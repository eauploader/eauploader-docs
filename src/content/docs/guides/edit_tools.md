---
title: '編集ツール'
description: 'EAUploaderに標準搭載されている編集ツールの使い方'
---

編集ツールは、編集画面の左側「編集ツール」から開きます。ツールは EAUploader のウィンドウの中に重なって表示され、編集画面で選んでいるアイテムに対して動作します。

## 共通の操作
* * *
ビューポイント位置エディタ以外のツールは、共通して次のような画面になっています。

| 場所 | 内容 |
| ---- | ---- |
| 上部 | ツール名、アイテム名、変更があるときは「未保存の変更あり」、右上に<span style="color: #00b0f0">戻る</span>ボタン |
| 左側 | ツールごとの設定 |
| 中央 | 変更を反映したプレビュー（操作は編集画面の 3D プレビューと同じです） |
| 下部 | <span style="color: #00b0f0">元に戻す</span>、<span style="color: #00b0f0">適用</span>ボタン |

* 変更は<span style="color: #00b0f0">適用</span>を押すまで保存されません。<span style="color: #00b0f0">元に戻す</span>を押すと、最後に保存した状態に戻ります。
* 保存しないまま<span style="color: #00b0f0">戻る</span>を押すと、保存するかどうかを確認するメッセージが表示されます。
* 変更は EAUploader の管理用コピーに保存されます。インポート元のアバターや衣装、元のテクスチャ・マテリアルは変更されません。
* ツールで作成したテクスチャやマテリアルは、アイテムのフォルダ（`Assets/EAUploader/Prefabs/<アイテム名>/`）に保存されます。
* 保存すると、アイテムのプレビュー画像も自動で作り直されます。

## ビューポイント位置エディタ
* * *
アバターの視点位置（VRChat 内で自分の目線になる位置）を設定します。VRCAvatarDescriptor を持つアバターで使用できます。

1. 左側の縦と横のバーを動かして、視点位置を変更します。移動中の位置が<span style="color: red">赤い点</span>、適用済みの位置が<span style="color: green">緑の点</span>で表示されます。
2. 上部の 🔄 ボタンを押すと、アバターを見る向きを反転できます。
3. 右側の「実際のビュー」は、視点位置から見たプレビューです。アバターの顔の内側が見えてしまっている場合は、背景がクリアに見えている状態まで移動してください。「1:1 (VR)」と「16:9 (PC)」で表示の比率を切り替えられます。
4. 位置が決まったら、<span style="color: #00b0f0">適用</span>ボタンを押してください。

:::note
ビューポイント位置エディタには「未保存の変更」の確認はありません。<span style="color: #00b0f0">適用</span>を押さずに<span style="color: #00b0f0">戻る</span>を押すと、動かした位置は破棄されます。
:::

## シェイプキー編集
* * *
体型や顔の形など、シェイプキー（ブレンドシェイプ）の初期値を調整して保存します。衣装に隠れる部分の体を縮めるといった用途にも使えます。シェイプキーを持つメッシュがあるアイテムで使用できます。

| 項目 | 内容 |
| ---- | ---- |
| メッシュ | 編集するメッシュを選びます。最初は、リップシンクに使われているメッシュ（無い場合はシェイプキーが最も多いメッシュ）が選ばれています。 |
| 顔を表示 / 全身を表示 | プレビューのカメラを顔又は全身に合わせます。 |
| シェイプキーを検索 | 名前でシェイプキーを絞り込みます。 |
| 変更したものだけ表示 | 保存されている値から変更したシェイプキーだけを表示します。 |
| シェイプキーの一覧 | スライダーか数値で値を変更します。行の右のボタンで、その行を保存済みの値に戻せます。 |
| このメッシュをリセット / すべて0にする | 選んでいるメッシュのシェイプキーをまとめて元に戻す、又は 0 にします。 |

「リップシンク」「まぶた」のマークが付いたシェイプキーは、VRChat の中で口の動きやまばたきに使われます。初期値を変えるとゲーム内で正しく表示されない場合があるので注意してください。

## テクスチャ編集
* * *
テクスチャの色を変えたり、別の画像に差し替えたりします。テクスチャを持つマテリアルがあるアイテムで使用できます。

1. 「マテリアル」から編集するマテリアルを選びます。このツールで作ったマテリアルには「編集済み」、まだ適用していない変更があるものには「変更あり」と表示されます。
2. 編集するテクスチャの種類（メインテクスチャ、影色、エミッションなど）を選びます。
3. 「色の調整」で、**色相**、**彩度**、**明るさ**、**コントラスト**、**色合い**（掛け合わせる色）を調整します。<span style="color: #00b0f0">画像を差し替え...</span>を押すと、画像ファイル（png, jpg）を元にすることもできます。
4. <span style="color: #00b0f0">適用</span>を押すと、調整したテクスチャと、それを使うマテリアルのコピーが作成され、アイテムに設定されます。

* 元のテクスチャとマテリアルは変更されません。編集したコピーは、適用したときにアイテムのフォルダに保存されます。
* 編集済みのマテリアルをもう一度編集すると、前回の調整値から編集を再開できます。調整を重ねても画質は劣化しません。
* <span style="color: #00b0f0">調整をリセット</span>で調整値を初期値に戻せます。<span style="color: #00b0f0">元のマテリアルに戻す</span>を押すと、編集前のマテリアルに戻ります。

## 着せ替え（対応衣装）
* * *
アバターに、そのアバター用に作られた衣装（対応衣装）やアクセサリーを着せます。VRCAvatarDescriptor を持ち、ジャンルが「アバター」のアイテムで使用できます。
着せる衣装やアクセサリーは、あらかじめアバター一覧にインポートし、ジャンルを「衣装」又は「アクセサリー」にしておいてください。

:::caution
このツールは、着せるアバター用に作られた衣装（同じボーン構造・同じ姿勢のもの）が対象です。他のアバター用の衣装を着せることはできません。
:::

### 画面の見方
| 項目 | 内容 |
| ---- | ---- |
| 状態 | Modular Avatar が導入されているかどうかと、衣装のボーンの扱い方が表示されます。 |
| 着用中 | 着せている衣装の一覧です。衣装ごとに表示・非表示を切り替えたり、<span style="color: #00b0f0">脱がせる</span>で衣装を外したりできます。 |
| アバターのパーツ | アバターに元から付いている服などのパーツです。衣装と一緒に表示したくないものはオフにしてください。<span style="color: #00b0f0">表示を元に戻す</span>で元の状態に戻せます。 |
| 衣装を追加 | ジャンルが「衣装」「アクセサリー」のアイテムが表示されます。名前やタグで検索して、クリックすると着せられます。 |

### 衣装を着せる
* ボーン構造を持つ衣装は、アバターのボーンに合わせて着せられます。
  * **Modular Avatar が導入されている場合** ― Modular Avatar の機能で衣装がセットアップされ、アバターのボーン構造は変更されません。
  * **Modular Avatar が導入されていない場合** ― 衣装のボーンは、アップロード時に作られるコピーの中でだけアバターのボーンに統合されます。アバター自体は変更されません。
* ボーン構造を持たないアクセサリーは、「取り付け先」（頭、首、胸、背骨、腰、手、足、アバターのルートなど）を選んで取り付けます。

### 保存する
* <span style="color: #00b0f0">適用</span> ― 着せた状態を、編集中のアバターに保存します。
* <span style="color: #00b0f0">新しいアバターとして保存</span> ― 着せた状態を、別のアバターとして保存します。元のアバターはそのまま残り、新しいアバターは VRChat に別のアバターとしてアップロードされます。

:::note
衣装はコピーして着せるため、着せた後にアバター一覧から衣装のアイテムを削除しても、アバターに着せた衣装は壊れません。
:::
