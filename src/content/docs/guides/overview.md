## EAUploaderを開く
* * *
EAUploader は、プロジェクトに追加されていれば Unity の起動時に自動でウィンドウが開きます。

ウィンドウを閉じてしまった場合は、Unity 上部のメニューから<span style="color: #00b0f0">EAUploader</span> → <span style="color: #00b0f0">Open EAUploader</span>を選択すると再び開くことができます。

:::note
Unity の起動直後や、スクリプトの読み込み中はウィンドウが開くまで少し時間がかかります。
Unity 右下のぐるぐる（読み込み中の表示）が消えるまでお待ちください。
:::

## ３つの画面
* * *
EAUploader は「アバター一覧」「編集画面」「アップロード」の３つの画面で構成されています。

```
アバター一覧 ──(カードをクリック)──▶ 編集画面 ──(アップロードへ進む)──▶ アップロード
     ▲                                  │ ▲                                    │
     └──────────(リストへ戻る)──────────┘ └────────────(編集に戻る)───────────┘
```

| 画面 | できること |
| ---- | ---- |
| **アバター一覧** | 最初に表示される画面です。アバターや衣装、アクセサリーをカードで一覧表示します。インポート、検索や絞り込み、タグの管理、設定はここから行います。 |
| **編集画面** | 選んだアイテムを 3D で確認しながら、名前やタグなどの情報を編集したり、編集ツールで改変したりします。 |
| **アップロード** | 編集画面の右側にシートとして開きます。VRChat へのログイン、アバター情報の設定、テスト、アップロードを行います。アップロードできるのはジャンルが「アバター」のアイテムだけです。 |

それぞれの画面の詳しい使い方は、以下のページを参照してください。

- [アバターのインポートと管理](/guides/import/)（アバター一覧）
- [編集画面](/guides/setup/)
- [編集ツール](/guides/edit_tools/)
- [アバターのアップロード](/guides/upload/)

## 基本的な作業の流れ
* * *
1. **アバター一覧**の<span style="color: #00b0f0">インポート</span>からアバターをインポートします。
2. シェーダーが見つからないエラーが表示された場合は、必要なシェーダーを導入します。（[シェーダーが見つからないエラー](/faq/missing_shader/)）
3. アバターのカードをクリックして**編集画面**を開き、「アップロードできます」と表示されることを確認します。必要に応じて編集ツールで調整します。
4. <span style="color: #00b0f0">アップロードへ進む</span>から**アップロード**のシートを開き、VRChat にログインしてアップロードします。

## ヘルプボタン
* * *
画面の各所にある<span style="color: #00b0f0">ヘルプ</span>ボタンを押すと、その項目についての説明が表示されます。
分からない項目があれば、まずはヘルプを確認してください。

## 画面内のメッセージ
* * *
確認のメッセージや設定、ヘルプなどは、EAUploader のウィンドウの中に重なって表示されます（モーダル）。
コピーや保存が完了したときは、画面の端に短い通知が表示されます。

## Unityのメニュー
* * *
Unity 上部のメニュー「EAUploader」から、以下の操作を行うことができます。

| メニュー | 内容 |
| ---- | ---- |
| Open EAUploader | EAUploader のウィンドウを開きます。 |
| Reload | アイテムの一覧や編集ツール、連携ツール（VRM Converter、AvatarOptimizer、Modular Avatar）の導入状況を再読み込みします。表示がおかしい場合や、連携ツールを導入した後にお試しください。 |
| ViewpointPositionEditor | 選択中のアバターのビューポイント位置エディタを開きます。 |
| Edit Tools | シェイプキー編集・テクスチャ編集・着せ替え（対応衣装）を開きます。（通常は編集画面から開きます） |

## 作業の保存について
* * *
EAUploader での操作は Unity に変更を行うものです。Unity は通常作業状態を保持するため、終了時に保存する操作は行いません。

ただし、EAUploader から削除したアイテムは Unity からも削除されます。削除の操作には十分ご注意ください。
