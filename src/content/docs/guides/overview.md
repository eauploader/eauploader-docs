## EAUploaderを開く
* * *
EAUploader は、プロジェクトに追加されていれば Unity の起動時に自動でウィンドウが開きます。

ウィンドウを閉じてしまった場合は、Unity 上部のメニューから<span style="color: #00b0f0">EAUploader</span> → <span style="color: #00b0f0">Open EAUploader</span>を選択すると再び開くことができます。

:::note
Unity の起動直後や、スクリプトの読み込み中はウィンドウが開くまで少し時間がかかります。
Unity 右下のぐるぐる（読み込み中の表示）が消えるまでお待ちください。
:::

## ３つのタブ
* * *
ウィンドウの上部に、３つのタブを切り替えるボタンがあります。作業は基本的に左のタブから順に進めます。

| タブ | できること |
| ---- | ---- |
| **インポート/設定** | アバターやシェーダーのインポート、モデルの管理、ツール内ガイド（EA Library）、言語などの設定を行います。 |
| **セットアップ** | アバターの状態の確認、名前の変更やピン留め、視点位置の設定などの編集ツールの起動を行います。 |
| **アップロード** | VRChat へのログイン、アバター情報の設定、テストビルド、アップロードを行います。 |

それぞれのタブの詳しい使い方は、以下のページを参照してください。

- [アバターのインポートと管理](/guides/import/)（インポート/設定タブ）
- [セットアップ（アバターの調整）](/guides/setup/)（セットアップタブ）
- [アバターのアップロード](/guides/upload/)（アップロードタブ）

## 基本的な作業の流れ
* * *
1. **インポート/設定タブ**でアバターをインポートします。
2. シェーダーが見つからないエラーが表示された場合は、必要なシェーダーを導入します。（[シェーダーが見つからないエラー](/faq/missing_shader/)）
3. **セットアップタブ**でアバターを選択し、「アップロードできます」と表示されることを確認します。必要に応じて編集ツールで調整します。
4. **アップロードタブ**で VRChat にログインし、アバターの名前などを設定してアップロードします。

## ヘルプボタン
* * *
画面の各所にある<span style="color: #00b0f0">ヘルプ</span>ボタンを押すと、その項目についての説明が表示されます。
分からない項目があれば、まずはヘルプを確認してください。

## Unityのメニュー
* * *
Unity 上部のメニュー「EAUploader」から、以下の操作を行うことができます。

| メニュー | 内容 |
| ---- | ---- |
| Open EAUploader | EAUploader のウィンドウを開きます。 |
| Reload | アバターの一覧や拡張機能、連携ツール（VRM Converter、AvatarOptimizer）の導入状況を再読み込みします。表示がおかしい場合や、連携ツールを導入した後にお試しください。 |
| ViewpointPositionEditor | 選択中のアバターのビューポイント位置エディタを開きます。（通常はセットアップタブから開きます） |

## 作業の保存について
* * *
EAUploader での操作は Unity に変更を行うものです。Unity は通常作業状態を保持するため、終了時に保存する操作は行いません。

ただし、EAUploader から削除したアバターは Unity からも削除されます。削除の操作には十分ご注意ください。
