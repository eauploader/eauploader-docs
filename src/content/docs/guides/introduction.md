## このドキュメントについて
このドキュメントでは、EAUploader の使い方や対応ツールの作成方法を説明します。

本ドキュメントは、EAUploader v1.4.6 の内容に準拠しています。

## EAUploaderとは？
EAUploader（Easy Avatar Uploader for VRChat）は、VRChat へアバターを「簡単に」アップロードできるようにUnityを簡単にするツールです。
Unity の拡張エディタとして動作し、アバターのインポートからアップロードまでを１つのウィンドウで行うことができます。

### このツールでできること
* **アバターのインポート** ― `.prefab` や `.unitypackage` で配布されているアバターをボタン１つで取り込みます。
* **アバターの管理** ― プロジェクト内のアバターをプレビュー画像付きの一覧で管理できます。
* **シェーダーの確認** ― アバターに必要なシェーダーが不足している場合にお知らせします。
* **VRMアバターの変換** ― 別ツール「VRM Converter for VRChat」を導入すると、VRM(0.x)アバターをVRChat用に変換できます。
* **視点位置の調整** ― 標準の編集ツール「ビューポイント位置エディタ」で視点位置を設定できます。
* **アバターの最適化** ― 別ツール「AvatarOptimizer」を導入すると、アップロード時に自動で最適化できます。
* **アバターのアップロード** ― 名前や公開設定、サムネイルを設定して VRChat へアップロードできます。PC用 / Android(Quest)用の切り替えにも対応しています。

### このツールでできないこと
EAUploader は既に VRChat 用につくられて完成しているアバター、又は VRM のみをサポートします。
着せ替えやアクセサリーの追加、表情の変更などのアバターの改変は行えません。改変を行う場合は、通常の Unity エディタを使用するか、EAUploader に対応した拡張機能を導入してください。

## 動作環境
| 項目 | 内容 |
| ---- | ---- |
| Unity | 2022.3 |
| VRChat SDK (Avatars) | 3.7.0 以上 |
| プロジェクト管理ソフト | VRChat Creator Companion(VCC) 又は ALCOM |

### 連携できるツール（任意）
| ツール | 導入すると使える機能 |
| ---- | ---- |
| [VRM Converter for VRChat](https://booth.pm/ja/items/1025226) | VRM(0.x)アバターのインポートと変換 |
| [AAO: Avatar Optimizer](https://booth.pm/ja/items/4885109) | アップロード時の自動最適化 |
