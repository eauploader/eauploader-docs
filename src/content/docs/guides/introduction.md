## このドキュメントについて
このドキュメントでは、EAUploader の使い方や対応ツールの作成方法を説明します。

本ドキュメントは、EAUploader v1.6.2 の内容に準拠しています。

## EAUploaderとは？
EAUploader（Easy Avatar Uploader for VRChat）は、VRChat へアバターを「簡単に」アップロードできるようにUnityを簡単にするツールです。
Unity の拡張エディタとして動作し、アバターや衣装の管理から簡単な改変、アップロードまでを１つのウィンドウで行うことができます。

### このツールでできること
* **アバター・衣装の管理** ― `.prefab` や `.unitypackage` で配布されているアバターや衣装、アクセサリーを取り込み、プレビュー画像付きのカードで一覧表示します。タグやメモ、ピン留めで整理できます。
* **元のデータを壊さない管理** ― インポートしたアバターは直接変更せず、EAUploader 専用のコピー（Prefab Variant）を作って管理します。
* **シェーダーの確認** ― アバターに必要なシェーダーが不足している場合にお知らせします。
* **簡単な改変** ― 標準の編集ツールで、視点位置の設定、シェイプキー（体型や表情）の調整、テクスチャの色変更、対応衣装の着せ替えができます。
* **VRMアバターの変換** ― 別ツール「VRM Converter for VRChat」を導入すると、VRM(0.x)アバターをVRChat用に変換できます。
* **アバターの最適化** ― 別ツール「AvatarOptimizer」を導入すると、アップロード時に自動で最適化できます。
* **アバターのアップロード** ― 名前や公開設定、サムネイルを設定して VRChat へアップロードできます。PC用に加えて、Quest（Android）用・iOS用にも一度にアップロードできます。

### このツールでできないこと
EAUploader は既に VRChat 用につくられて完成しているアバター、又は VRM を対象としています。
標準の編集ツールでは、そのアバター用に作られた衣装（対応衣装）の着せ替えや、色・体型の調整などの簡単な改変ができますが、非対応衣装の着せ替えやギミックの導入などの本格的な改変は行えません。その場合は、通常の Unity エディタを使用するか、EAUploader に対応した拡張機能を導入してください。

## 動作環境
| 項目 | 内容 |
| ---- | ---- |
| Unity | 2022.3 |
| VRChat SDK (Avatars) | 3.7.0 以上 |
| プロジェクト管理ソフト | VRChat Creator Companion(VCC) 又は ALCOM |

### 連携できるツール（任意）
| ツール | 導入すると使える機能 |
| ---- | ---- |
| [VRM Converter for VRChat](https://booth.pm/ja/items/1025226) | VRM(0.x)アバターのインポートと変換 |
| [AAO: Avatar Optimizer](https://booth.pm/ja/items/4885109) | アップロード時の自動最適化 |
| [Modular Avatar](https://modular-avatar.nadena.dev/ja/) | 着せ替え（対応衣装）で、アバターのボーン構造を変えずに衣装をセットアップ |
