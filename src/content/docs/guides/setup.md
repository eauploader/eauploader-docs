**セットアップ**タブでは、アバターの状態の確認や、編集ツールを使ったアバターの調整を行います。

画面は左から「アバターの一覧」「プレビュー」「編集ツール」の３つに分かれています。

## アバターを選択する
* * *
左側の一覧から、調整したいアバターを選択してください。

* 一覧には、「モデルの管理」で非表示にしたもの以外のプレハブが表示されます。
* ピン留めしたアバターは一覧の上部に表示されます。
* 上部の入力欄で名前を検索したり、ドロップダウンで並び順を変更したりできます。

ここで選択したアバターは、アップロードタブでも選択された状態になります。

## アバターのプレビュー
* * *
アバターを選択すると、中央の上部にアバターの名前とアバターの高さ（視点の高さ）、その下にアバターのプレビューが表示されます。

プレビューは以下の操作で動かすことができます。

| 操作 | 動作 |
| ---- | ---- |
| 左クリックしながら移動 | 回転 |
| 右クリックしながら移動 | 移動 |
| ホイール上下 | 拡大縮小 |
| 左下のボタン | 位置をリセット |

### 名前の変更・ピン留め・削除
プレビューの下にあるボタンから、選択中のアバターに対して以下の操作ができます。

| ボタン | 内容 |
| ---- | ---- |
| ✏（えんぴつ） | プレハブの名前を変更します。 |
| 📌（ピン） | アバターをピン留めします。ピン留めしたアバターは一覧の上部に表示されます。もう一度押すとピン留めを解除します。 |
| 🗑（ゴミ箱） | プレハブを削除します。**削除したプレハブは Unity のプロジェクトからも削除されます。** |

## アバターの状態を確認する
* * *
右側の「編集ツール」の上部には、選択中のアバターの状態が表示されます。

| 表示 | 意味と対処方法 |
| ---- | ---- |
| ✅ アップロードできます | このままアップロードできます。 |
| VRCAvatarDescriptorがありません | VRChat 用のアバターではありません。VRChat 用として配布されているアバターであれば、正しいプレハブを選択しているか確認してください。 |
| シェーダーがありません | アバターに必要なシェーダーがプロジェクトにありません。「[シェーダーが見つからないエラー](/faq/missing_shader/)」を参照してください。 |
| VRMアバターをVRChatアバターに変換する必要があります | VRMアバターです。<span style="color: #00b0f0">VRChatアバターに変換</span>ボタンから変換してください。詳しくは「[VRMアバターを使う](/guides/vrm/)」を参照してください。 |
| This avatar is a converted VRM, Viewpoint Position may need to be adjusted. | VRMから変換したアバターです。視点位置の調整が必要な場合があります。下記の「ビューポイント位置エディタ」で視点位置を確認してください。 |

## 編集ツールを使う
* * *
「編集ツール」には、アバターを調整、カスタマイズするためのツールが一覧で表示されます。ツールの名前のボタンを押すとツールが開きます。

ボタンの右側の ▼ を押すと、ツールの説明、バージョン、制作者が表示されます。ツールによってはサポートページへのリンクも表示されます。

選択中のアバターでは使用できないツールは、ボタンが押せない状態になり、使用できない理由が表示されます。

### ビューポイント位置エディタ
ビューポイント位置エディタは、EAUploader に標準で搭載されている編集ツールです。アバターの視点位置（VRChat 内で自分の目線になる位置）を設定できます。

1. 左側の縦と横のバーを動かして、視点位置を変更します。現在設定されている位置が<span style="color: red">赤い点</span>、新たに移動した点が<span style="color: green">緑の点</span>で表示されます。
2. 上部の 🔄 ボタンを押すと、アバターを見る向きを反転できます。
3. 右側の「実際のビュー」は、視点位置から見たプレビューです。アバターの顔の内側が見えてしまっている場合は、背景がクリアに見えている状態まで移動してください。「1:1 (VR)」と「16:9 (PC)」で表示の比率を切り替えられます。
4. 位置が決まったら、<span style="color: #00b0f0">適用</span>ボタンを押してください。

:::note
ビューポイント位置エディタを使用するには、アバターに VRCAvatarDescriptor が必要です。VRMアバターの場合は、先に VRChat 用アバターへ変換してください。
:::

## 拡張機能を導入する
* * *
EAUploader に対応した拡張機能（プラグイン）を導入することで、EAUploader でサポートしていないアバターの設定や編集を行えるようになります。導入した拡張機能は「編集ツール」の一覧に追加されます。

* <span style="color: #00b0f0">拡張機能をインポート</span> ― 拡張機能の `.unitypackage` ファイルを選択してインポートします。
* <span style="color: #00b0f0">他の拡張機能を探す</span> ― 拡張機能を紹介している Web サイトを開きます。

拡張機能が VCC（又は ALCOM）に対応している場合は、VCC からプロジェクトに追加することもできます。

:::tip
拡張機能を作ってみたい方は「[クイックスタートガイダンス](/for_tooldev/extension/)」をご覧ください。
:::
