---
title: '編集画面'
description: '編集画面の使い方'
---

**編集画面**では、選んだアイテムを 3D で確認しながら、名前やタグなどの情報を編集したり、編集ツールで改変したりします。
アバター一覧でカードをクリックするか、カードの<span style="color: #00b0f0">編集</span>ボタンを押すと開きます。

## 画面の構成
* * *
画面全体にアイテムの 3D プレビューが表示され、その上に次のパネルが重なっています。

| 場所 | 内容 |
| ---- | ---- |
| 上部 | <span style="color: #00b0f0">リストへ戻る</span>ボタン、開いているアイテムの名前とジャンル |
| 左側「編集ツール」 | アイテムの状態と、編集ツールの一覧 |
| 右側「アイテム情報」 | サムネイル、名前、ジャンル、タグ、メモなどの情報 |

左右のパネルは、パネルの右上のボタンで折りたたむことができます。折りたたんだパネルは、画面の端に表示されるボタンから再び開けます。

## 3D プレビュー
* * *
| 操作 | 動作 |
| ---- | ---- |
| 左クリックしながら移動 | 回転 |
| 右クリックしながら移動 | 移動 |
| ホイール上下 | 拡大縮小 |
| リセットボタン | 表示をリセット |

## アイテムの状態を確認する
* * *
「編集ツール」の上部には、アイテムの状態が表示されます。

| 表示 | 意味と対処方法 |
| ---- | ---- |
| ✅ アップロードできます | このままアップロードできます。 |
| VRCAvatarDescriptorがありません | VRChat 用のアバターではありません。衣装やアクセサリーの場合は問題ありません。VRChat 用として配布されているアバターであれば、正しいPrefabを選んでいるか確認してください。 |
| シェーダーがありません | アイテムに必要なシェーダーがプロジェクトにありません。「[シェーダーが見つからないエラー](/faq/missing_shader/)」を参照してください。 |
| VRMアバターをVRChatアバターに変換する必要があります | VRMアバターです。<span style="color: #00b0f0">VRChatアバターに変換</span>ボタンから変換してください。詳しくは「[VRMアバターを使う](/guides/vrm/)」を参照してください。 |
| This avatar is a converted VRM, Viewpoint Position may need to be adjusted. | VRMから変換したアバターです。視点位置の調整が必要な場合があります。「[ビューポイント位置エディタ](/guides/edit_tools/#ビューポイント位置エディタ)」で視点位置を確認してください。 |

## 編集ツールを使う
* * *
「編集ツール」には、アイテムを調整するためのツールが一覧で表示されます。ツールの名前のボタンを押すと、ツールが EAUploader のウィンドウの中に開きます。

ボタンの右側の ▼ を押すと、ツールの説明、バージョン、制作者が表示されます。選んでいるアイテムでは使用できないツールは、ボタンが押せない状態になり、使用できない理由が表示されます。

EAUploader には次の編集ツールが標準で搭載されています。使い方は「[編集ツール](/guides/edit_tools/)」を参照してください。

| ツール | 内容 |
| ---- | ---- |
| ビューポイント位置エディタ | アバターの視点位置を設定します。 |
| シェイプキー編集 | 体型や表情などのシェイプキーの初期値を調整します。 |
| テクスチャ編集 | テクスチャの色を変えたり、別の画像に差し替えたりします。 |
| 着せ替え（対応衣装） | そのアバター用に作られた衣装やアクセサリーを着せます。 |

EAUploader に対応した拡張機能を導入すると、ここにツールが追加されます。

## アイテム情報を編集する
* * *
右側の「アイテム情報」では、アイテムの情報を編集できます。変更はすぐに保存されます。

### サムネイル
アイテムのサムネイル（一覧に表示されるプレビュー画像）です。

* 🔄 ボタン（プレビューを再生成する）― 現在のアイテムの見た目からプレビュー画像を作り直します。編集ツールで見た目を変えたときなどにお使いください。
* <span style="color: #00b0f0">サムネイルを変更</span> ― 画像ファイル（png, jpg）を選んで、サムネイルを差し替えます。

### 名前
アイテムの名前です。入力欄からフォーカスを外すか Enter キーを押すと反映されます。
名前を変えると EAUploader の管理用コピーのファイル名が変わります。インポート元のPrefabの名前は変わりません。

### ジャンル
「アバター」「衣装」「アクセサリー」「その他」から選びます。アップロードできるのはジャンルが「アバター」のアイテムだけです。
ジャンルはアバター一覧のカテゴリでの絞り込みや、着せ替え（対応衣装）で着せる衣装の一覧に使われます。

### タグ
入力欄に入力すると、既存のタグの候補が表示されます。候補を選ぶか、Enter キーを押すとタグが追加されます。まだ無いタグ名の場合は<span style="color: #00b0f0">新しいタグを作成</span>で追加できます。
追加したタグの × を押すと、そのアイテムからタグを外せます。

タグ名は 32 文字までです。プロジェクト全体のタグやグループは、アバター一覧の<span style="color: #00b0f0">タグの設定</span>で管理できます。

### メモ
自由にメモを残せます。入力欄からフォーカスを外すと保存されます。

### ピン留め・一覧で非表示にする
* **ピン留め** ― オンにすると、アバター一覧の先頭に表示されます。
* **一覧で非表示にする** ― オンにすると、アバター一覧に表示されなくなります（「非表示のアイテムも表示」をオンにすると確認できます）。

ピン留めと非表示は同時には設定できません。

### 詳細
最終更新日、アバターの高さ（視点の高さ）、Blueprint ID、保存先（EAUploader の管理用コピーのパス）が表示されます。
Blueprint ID は伏せ字で表示され、👁 ボタンで表示を切り替えられます。Blueprint ID と保存先は、コピーボタンでクリップボードにコピーできます。

:::danger
Blueprint ID を他人に公開しないでください。詳しくは「[アバターのアップロード](/guides/upload/#blueprint)」を参照してください。
:::

### 複製・削除
* <span style="color: #00b0f0">複製</span> ― アイテムをもう１つ作り、複製したほうを開きます。改変前の状態を残しておきたいときや、同じアバターで別の改変をしたいときにお使いください。複製したものもインポート元のPrefabを元にした管理用コピーなので、元のデータには影響しません。
* <span style="color: #00b0f0">削除</span> ― アイテムを削除します。詳しくは「[アイテムを削除する](/guides/import/#アイテムを削除する)」を参照してください。

## アップロードへ進む
* * *
ジャンルが「アバター」のアイテムでは、アイテム情報の下部に<span style="color: #00b0f0">アップロードへ進む</span>ボタンが表示されます。押すと、画面の右側にアップロードのシートが開きます。
使い方は「[アバターのアップロード](/guides/upload/)」を参照してください。
