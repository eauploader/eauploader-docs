---
title: 'アバターのアップロード'
description: 'アップロードタブの使い方'
---

**アップロード**タブでは、VRChat へのログイン、アバター情報の設定、テストビルド、アップロードを行います。

## アップロードの前に
* * *
アバターをアップロードするには、以下の条件を満たしている必要があります。

* VRChat のアカウントにログインしていること
* VRChat のトラストランクが **New User** 以上であること
* アバターに VRCAvatarDescriptor があり、必要なシェーダーがプロジェクトに導入されていること（セットアップタブで「アップロードできます」と表示されていること）

:::note
トラストランクが足りない場合は、VRChat で過ごし、フレンドを増やすことでランクを上げることができます。又は、VRChat+ に加入（有料）することで即時ランクを上げることができます。
:::

## アバターを選択する
* * *
左側の一覧から、アップロードしたいアバターを選択してください。選択するとプレビューが表示されます。

既に VRChat にアップロードしたことがあるアバターは、プレハブの名前の下に VRChat 上のアバターの名前が表示されます。

「アップロードできません」と表示されているアバターは選択できません。VRMアバターの場合は、セットアップタブで VRChat 用アバターへ変換してください。
アバターが一覧に表示されない場合は、モデルの管理で非表示にしていないか確認してください。

## VRChatへログイン
* * *
VRChat にログインしていない場合は、<span style="color: #00b0f0">ログイン</span>ボタンが表示されます。
ボタンを押すと VRChat SDK のコントロールパネルが開きますので、VRChat のアカウントでログインしてください。

ログインすると、ログインしているユーザー名と、アバターのアップロード権限が表示されます。

## アバター情報を設定する
* * *
| 項目 | 説明 |
| ---- | ---- |
| アバターの名前 | アバターに名前を設定してください。**この項目は必須です。** |
| アバターの説明 | アバターの説明欄です。自分用のメモとして使用します。入力しなくてもアップロードできます。 |
| 警告の設定 | アバターの内容に応じてタグを設定してください。「性的な示唆」「成人向けの言葉・表現」「暴力的な表現」「過剰な流血・血糊」「過激なホラー」から選択できます。該当するアバターにタグを付けずに使用すると、違反となる場合があります。 |
| 公開設定 | Private: 自分のみが使用できます。<br />Public: 誰でも使用できるように公開されます。 |

:::danger
ネット上で配布・販売されているアバターは、基本的に Public で公開することが禁止されています。
自身で制作したアバターでない場合は、Public でアップロードしないでください。
:::

### サムネイルを設定する
アバターのサムネイルを設定します。サムネイルは VRChat 内のアバター一覧などに表示されます。

EAUploader では、デフォルトでインポート時に生成されたプレビュー画像が設定されます。
<span style="color: #00b0f0">サムネイルを変更</span>から画像ファイル（png, jpg）を選択すると、サムネイルを変更できます。変更時に「EAUploaderのアバターリストのサムネイルにも適用しますか？」と表示されますので、一覧のプレビュー画像も変更したい場合は<span style="color: #00b0f0">はい</span>を選択してください。

<span style="color: #00b0f0">プレビュー画像を使用（デフォルト）</span>を押すと、プレビュー画像に戻します。

## アップロード済みのアバターの場合
* * *
既に VRChat にアップロードしたことがあるアバターを選択した場合、VRChat 上の情報が読み込まれて各項目に入力されます。また、以下の情報が表示されます。

* **VRChat上の情報** ― 制作者、アップロード日、最終更新日、更新回数
* **Blueprint** ― VRChat 上でアバターに割り当てられた ID の操作

### アバター情報だけを更新する
アバターの名前や説明、警告の設定、公開設定、サムネイルを変更すると、<span style="color: #00b0f0">保存</span>と<span style="color: #00b0f0">破棄</span>のボタンが表示されます。

* <span style="color: #00b0f0">保存</span> ― アバターを再アップロードせずに、VRChat 上のアバター情報だけを更新します。
* <span style="color: #00b0f0">破棄</span> ― 変更を取り消して、VRChat 上の情報に戻します。

### Blueprint
Blueprint（Blueprint ID）は、VRChat 上でアバターに割り当てられた個別の ID です。同じ Blueprint ID を持つアバターをアップロードすると、VRChat 上のアバターが上書き（更新）されます。

* <span style="color: #00b0f0">コピー</span> ― Blueprint ID をクリップボードにコピーします。
* <span style="color: #00b0f0">VRChatとの紐づけを切る</span> ― アバターに新しい ID を割り当てます。次回のアップロードでは、VRChat 上の既存のアバターを上書きせず、別のアバターとしてアップロードされます。

:::danger
Blueprint ID を他人に公開しないでください。この ID を使用することで、VRChat 上のアバターを更新、削除できるため、他者に公開するとアバターのデータを盗まれる可能性があります。
:::

## アバターの最適化
* * *
別ツールの「AAO: Avatar Optimizer（by anatawa12）」をプロジェクトに導入すると、<span style="color: #00b0f0">自動最適化（AvatarOptimizerを使用）</span>を使用できます。

オンにすると、アバターに AvatarOptimizer の自動最適化コンポーネント「Trace And Optimize」が追加され、ビルド時にアバターの見た目を変えずに非破壊で最適化されます。オフにするとコンポーネントを削除します。

* 最適化の結果はビルドするまで分かりません。下の「アバターパフォーマンス」には最適化後の結果は反映されません。
* 最適化の設定は EAUploader から変更できません。設定を変更する場合や、他の最適化機能を使用する場合は Unity エディタで行う必要があります。
* AvatarOptimizer が導入されていない状態でオンにすると、導入を案内するメッセージが表示されます。AvatarOptimizer は [Booth](https://booth.pm/ja/items/4885109) 又は VCC から導入できます。導入後は、メニューの「EAUploader」→「Reload」を実行してください。

## アバターパフォーマンス
* * *
VRChat では、アバターの負荷に応じて５段階の評価が付けられます。プレイヤーはこの評価に基づいてアバターを非表示にすることができ、負荷の高いアバターは一部プレイヤーには表示されない場合があります。

軽い方から順に **Excellent - Good - Medium - Poor - Very Poor** と評価されます。
アバターの総合評価は一番上の **Overall** の値です。その下に、ポリゴン数やマテリアルスロット、PhysBone コンポーネントなどの項目ごとの評価が表示されます。

Good まで最適化 / 軽量化することを VRChat は推奨していますが、PC用のアバターは Very Poor でも問題なくアップロードできます。

:::note
EAUploader に表示されるパフォーマンスは PC（Windows）用の基準で計算したものです。Android 用のアバターには様々な制約があり、制限を超えるアバターは Android（Quest / スマホ）のユーザーには表示されません。
:::

## プラットフォームを選択する
* * *
アバターはデスクトップ（PCVR）のみで使用できるアバターと、Android（Quest / スマホ）でも使用できるアバターに分かれます。
「PC用 / Quest用 切り替え」から、ビルドするプラットフォームを選択してください。

| プラットフォーム | 説明 |
| ---- | ---- |
| Windows | PC 用のアバターとしてビルドします。 |
| Android | Quest 単体やスマートフォン用のアバターとしてビルドします。Unity に Android Build Support モジュールを追加する必要があります。 |
| iOS | iOS 用のアバターとしてビルドします。iOS へのアップロードが許可されているアカウントの場合のみ表示されます。 |

プラットフォームを切り替えると、確認のメッセージが表示されます。切り替えには少し時間がかかります。

Android Build Support モジュールが導入されていない状態で Android を選択すると、モジュールのダウンロードを案内するメッセージが表示されます。Unity Hub の「インストール」から、使用している Unity のバージョンに「Android Build Support」モジュールを追加してください。

:::tip
PC と Android の両方に対応させたい場合は、まず Windows でアップロードし、プラットフォームを Android に切り替えてから、同じアバターをもう一度アップロードしてください。同じ Blueprint ID のアバターに、Android 用のデータが追加されます。
Android 用としてアップロードするアバターは、Quest 対応アバターである必要があります。アバターの配布元で Quest 対応かどうか確認してください。
:::

## テストとしてビルドする
* * *
<span style="color: #00b0f0">テストとしてビルド</span>を押すと、ローカル（自身のPC内）でアバターをビルドし、VRChat で使用できるようにします。アップロードせずにアバターの動作確認をすることができます。

テストとしてビルドされたアバターは VRChat にはアップロードされません。そのため、他プレイヤーにはアバターが見えません。
テストとしてビルドしたアバターは、VRChat アプリ内でアバターメニュー内の「Other」から選択できます。

:::note
テストとしてビルドは、プラットフォームが Windows の場合のみ使用できます。
:::

## アップロードする
* * *
1. アバターの名前を入力します。
2. 「上記の設定は正しく、私はVRChatにアバターをアップロードすることを確認しました。」にチェックを入れます。
3. <span style="color: #00b0f0">アップロード</span>ボタンを押します。

アップロード中は進捗を示すバーが表示されます。アップロードが完了したアバターは VRChat 内で使用できます。

### アップロードに失敗する場合
* **アバターのサイズが大きすぎる** ― アバターのファイルサイズが VRChat の上限を超えています。エラーメッセージに上限と現在のサイズが表示されますので、アバターを軽量化してください。
* **その他のエラー** ― エラーが発生すると「エラーレポート」が表示されます。詳しくは「[よくある質問とトラブルシューティング](/faq/troubleshooting/)」を参照してください。
