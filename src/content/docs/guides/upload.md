---
title: 'アバターのアップロード'
description: 'アップロードの使い方'
---

アップロードは、編集画面の右側に開く「VRChat にアップロード」のシートで行います。
編集画面の<span style="color: #00b0f0">アップロードへ進む</span>ボタン、又はアバター一覧のカードの<span style="color: #00b0f0">アップロード</span>ボタンから開きます。<span style="color: #00b0f0">編集に戻る</span>を押すとシートが閉じます。

## アップロードの前に
* * *
アバターをアップロードするには、以下の条件を満たしている必要があります。

* アイテムのジャンルが「アバター」であること
* アバターに VRCAvatarDescriptor があり、必要なシェーダーがプロジェクトに導入されていること（編集画面で「アップロードできます」と表示されていること）
* VRChat のアカウントにログインしていること
* VRChat のトラストランクが **New User** 以上であること

条件を満たしていない場合は、「このアバターは以下の理由でアップロードできません」と理由が表示されます。

:::note
トラストランクが足りない場合は、VRChat で過ごし、フレンドを増やすことでランクを上げることができます。又は、VRChat+ に加入（有料）することで即時ランクを上げることができます。
:::

## VRChatへログイン
* * *
VRChat にログインしていない場合は、<span style="color: #00b0f0">ログイン</span>ボタンが表示されます。
ボタンを押すと VRChat SDK のコントロールパネルが開きますので、VRChat のアカウントでログインしてください。

ログインすると、ログインしているユーザー名と、アバターのアップロードが許可されているかどうかが表示されます。

## VRChat での表示を設定する
* * *
| 項目 | 説明 |
| ---- | ---- |
| サムネイル | アバターのサムネイルです。デフォルトでは EAUploader のプレビュー画像が使われます。<span style="color: #00b0f0">サムネイルを変更</span>から画像ファイル（png, jpg）を選んで変更できます。変更時に「EAUplaoderのアバターリストのサムネイルにも適用しますか？」と表示されますので、一覧のプレビュー画像も変更したい場合は<span style="color: #00b0f0">はい</span>を選んでください。サムネイルの横のボタンで、プレビュー画像に戻せます。 |
| アバターの名前 | VRChat で表示されるアバターの名前です。**この項目は必須です。** |
| アバターの説明 | アバターの説明欄です。自分用のメモとして使用します。入力しなくてもアップロードできます。 |
| 公開設定 | 非公開: 自分のみが使用できます。<br />公開: 誰でも使用できるように公開されます。 |

:::danger
ネット上で配布・販売されているアバターは、基本的に公開（Public）にすることが禁止されています。
自身で制作したアバターでない場合は、公開でアップロードしないでください。
:::

### 警告の設定
アバターの内容に応じてタグを設定してください。「性的な示唆」「成人向けの言葉・表現」「暴力的な表現」「過剰な流血・血糊」「過激なホラー」から選択できます。
該当するアバターにタグを付けずに使用すると、違反となる場合があります。

## アップロード済みのアバターの場合
* * *
既に VRChat にアップロードしたことがあるアバターでは、VRChat 上の情報が読み込まれて各項目に入力されます。また、「VRChat上の情報」として制作者、アップロード日、更新回数が表示されます。

### アバター情報だけを更新する
名前や説明、公開設定、警告の設定、サムネイルを変更すると、<span style="color: #00b0f0">保存</span>と<span style="color: #00b0f0">破棄</span>のボタンが表示されます。

* <span style="color: #00b0f0">保存</span> ― アバターを再アップロードせずに、VRChat 上のアバター情報だけを更新します。
* <span style="color: #00b0f0">破棄</span> ― 変更を取り消して、VRChat 上の情報に戻します。

### Blueprint
Blueprint（Blueprint ID）は、VRChat 上でアバターに割り当てられた個別の ID です。同じ Blueprint ID を持つアバターをアップロードすると、VRChat 上のアバターが上書き（更新）されます。

* <span style="color: #00b0f0">コピー</span> ― Blueprint ID をクリップボードにコピーします。
* <span style="color: #00b0f0">VRChatとの紐づけを切る</span> ― アバターに新しい ID を割り当てます。次回のアップロードでは、VRChat 上の既存のアバターを上書きせず、別のアバターとしてアップロードされます。

:::danger
Blueprint ID を他人に公開しないでください。この ID を使用することで、VRChat 上のアバターを更新、削除できるため、他者に公開するとアバターのデータを盗まれる可能性があります。
:::

## プラットフォームを選ぶ
* * *
「プラットフォーム」で、アップロード先を選びます。

| プラットフォーム | 説明 |
| ---- | ---- |
| Windows | PC 用のアバターです。必ずアップロードされます。 |
| Quest（Android） | オンにすると、Quest 単体やスマートフォン用のアバターも一緒にアップロードします。Unity に Android Build Support モジュールが必要です。 |
| iOS | オンにすると、iOS 用のアバターも一緒にアップロードします。iOS へのアップロードが許可されているアカウントの場合のみ表示されます。Unity に iOS Build Support モジュールが必要です。 |

複数のプラットフォームを選んだ場合、アップロード中にビルドターゲットが切り替わり、完了後に Windows へ戻ります。時間がかかる場合があります。

必要なモジュールが導入されていない状態でオンにすると、モジュールのダウンロードを案内するメッセージが表示されます。Unity Hub の「インストール」から、使用している Unity のバージョンにモジュールを追加してください。

:::caution
Quest（Android）用としてアップロードするアバターは、Quest 対応アバターである必要があります。アバターの配布元で Quest 対応かどうか確認してください。
:::

## アバターパフォーマンス
* * *
VRChat では、アバターの負荷に応じて５段階の評価が付けられます。プレイヤーはこの評価に基づいてアバターを非表示にすることができ、負荷の高いアバターは一部プレイヤーには表示されない場合があります。

軽い方から順に **Excellent - Good - Medium - Poor - Very Poor** と評価されます。
総合評価が表示され、<span style="color: #00b0f0">内訳を見る</span>を押すと、ポリゴン数やマテリアルスロット、PhysBone コンポーネントなどの項目ごとの評価を確認できます。

Good まで最適化 / 軽量化することを VRChat は推奨していますが、PC用のアバターは Very Poor でも問題なくアップロードできます。

:::note
EAUploader に表示されるパフォーマンスは PC（Windows）用の基準で計算したものです。Android 用のアバターには様々な制約があり、制限を超えるアバターは Android（Quest / スマホ）のユーザーには表示されません。
:::

## アバターの最適化
* * *
別ツールの「AAO: Avatar Optimizer（by anatawa12）」をプロジェクトに導入すると、<span style="color: #00b0f0">自動最適化（AvatarOptimizerを使用）</span>を使用できます。

オンにすると、アバターに AvatarOptimizer の自動最適化コンポーネント「Trace And Optimize」が追加され、アップロード時にアバターの見た目を変えずに非破壊で最適化されます。オフにするとコンポーネントを削除します。

* 最適化の結果はビルドするまで分かりません。アバターパフォーマンスには最適化後の結果は反映されません。
* 最適化の設定は EAUploader から変更できません。設定を変更する場合や、他の最適化機能を使用する場合は Unity エディタで行う必要があります。
* AvatarOptimizer が導入されていない状態でオンにすると、導入を案内するメッセージが表示されます。AvatarOptimizer は [Booth](https://booth.pm/ja/items/4885109) 又は VCC から導入できます。導入後は、メニューの「EAUploader」→「Reload」を実行してください。

## テストする
* * *
シートの下部にある<span style="color: #00b0f0">テスト</span>を押すと、ローカル（自身のPC内）でアバターをビルドし、VRChat で使用できるようにします。アップロードせずにアバターの動作確認をすることができます。

テストとしてビルドされたアバターは VRChat にはアップロードされません。そのため、他プレイヤーにはアバターが見えません。
テストとしてビルドしたアバターは、VRChat アプリ内でアバターメニュー内の「Other」から選択できます。

:::note
テストは、Unity のビルドターゲットが Windows の場合のみ使用できます。
:::

## アップロードする
* * *
1. アバターの名前を入力します。
2. 「上記の設定は正しく、私はVRChatにアバターをアップロードすることを確認しました。」にチェックを入れます。
3. <span style="color: #00b0f0">アップロード</span>ボタンを押します。

アップロード中は進捗が表示されます。<span style="color: #00b0f0">アップロードをキャンセル</span>で中止することもできます。アップロードが完了したアバターは VRChat 内で使用できます。

:::note
アップロードは、アバターのコピーをシーン上に一時的に作成して行います。Modular Avatar や AvatarOptimizer などの非破壊ツールの処理はこのコピーに対して行われるため、EAUploader の管理用コピーは変更されません。
:::

### アップロードに失敗する場合
アップロードに失敗すると「アップロード失敗」のメッセージに原因が表示されます。アバターのファイルサイズが VRChat の上限を超えている場合などは、アバターを軽量化してください。
また、エラーが発生すると「エラーレポート」が表示されます。詳しくは「[よくある質問とトラブルシューティング](/faq/troubleshooting/)」を参照してください。
