**インポート/設定**タブでは、アバターやシェーダーのインポート、プロジェクト内のモデルの管理、ツールの設定を行います。

画面は左から「インポート・設定」「モデルの管理」「EA Library」の３つに分かれています。

## アバターをインポートする
* * *
### 対応しているファイル形式
EAUploader でインポートできるアバターのファイル形式は以下の通りです。

| 形式 | 説明 |
| ---- | ---- |
| `.prefab` | プレハブ。アバター本体（体や服などの各部分）をまとめたものです。基本的にプレハブ＝アバター本体です。 |
| `.unitypackage` | パッケージ。アバター本体やシェーダー、着せ替え用の服などがまとめられて配布されています。 |
| `.vrm` | VRMアバター（ver. 0.x のみ）。VRM Converter for VRChat の導入が必要です。詳しくは「[VRMアバターを使う](/guides/vrm/)」を参照してください。 |

:::caution
EAUploader が対応しているのは、**VRChat 用に作成されているアバター**です。VRChat 用として販売・配布されているアバターをご用意ください。
:::

### ファイルを選択してインポートする
<span style="color: #00b0f0">アバターをインポート</span>にある<span style="color: #00b0f0">インポート</span>ボタンを押し、ダウンロードしたアバターのファイル（`.prefab` 又は `.unitypackage`）を選択してください。

`.unitypackage` を選択した場合、Unity のインポート確認画面は表示されず、パッケージの内容がすべてプロジェクトに追加されます。

### フォルダからまとめてインポートする
複数のアバターをまとめてインポートしたい場合は、<span style="color: #00b0f0">フォルダからインポート</span>ボタンを押してフォルダを選択してください。

選択したフォルダ（その中のフォルダも含む）にある `.prefab` と `.unitypackage` がすべてインポートされます。インポートの前に、インポートされるファイルの一覧が表示されますので、確認してから<span style="color: #00b0f0">インポート</span>を押してください。

### ドラッグ＆ドロップでインポートする
エクスプローラーからファイルを「モデルの管理」の一覧にドラッグ＆ドロップすることでもインポートできます。
`.unitypackage`、`.prefab` に加えて、VRM Converter for VRChat を導入している場合は `.vrm` もドロップできます。

### インポートした後に行われること
アバター（プレハブ）がインポートされると、EAUploader は自動で以下の処理を行います。

* **シェーダーの確認** ― アバターに設定されているシェーダーがプロジェクト内に無い場合、「シェーダーの問題が見つかりました」というメッセージを表示します。この場合は「[シェーダーが見つからないエラー](/faq/missing_shader/)」を参照してシェーダーを導入してください。
* **プレビュー画像の作成** ― 一覧に表示するためのプレビュー画像を作成します。

## シェーダーをインポートする
* * *
<span style="color: #00b0f0">シェーダーをインポート</span>ボタンから、シェーダーを含む `.unitypackage` ファイルをインポートできます。

<span style="color: #00b0f0">導入済みのシェーダーを確認</span>ボタンを押すと、プロジェクトに導入されているシェーダーの一覧が表示されます。
一覧では、一部の VRChat 非対応シェーダーを除外して表示しています。

:::tip
シェーダーは `.unitypackage` でも配布されていますが、VCC（又は ALCOM）に対応しているシェーダーは VCC から追加することを強く推奨します。
VCC で管理することで、簡単にアップデートを行うことができます。
:::

## モデルの管理
* * *
中央の「モデルの管理」には、プロジェクトの `Assets` フォルダ内にある**すべての `.prefab`** が一覧で表示されます。つまり、アバター以外のもの（衣装やアクセサリーなど）も表示される場合があります。

### 一覧の見方
各項目には、プレビュー画像、プレハブの名前、最終更新日が表示されます。
アバターに問題がある場合は、以下の警告が表示されます。

| 警告 | 意味 |
| ---- | ---- |
| アップロードできません | VRChat 用のアバターではありません（VRCAvatarDescriptor がありません）。衣装やアクセサリーのプレハブの場合もこの表示になります。 |
| VRMアバターをVRChatアバターに変換する必要があります | VRMアバターです。アップロードするには変換が必要です。 |
| 設定されたシェーダーが見つかりません | アバターに必要なシェーダーがプロジェクトにありません。 |

プレビュー画像をクリックすると、画像を大きく表示します。表示されたウィンドウの<span style="color: #00b0f0">プレビューを再生成する</span>から、プレビュー画像を作り直すこともできます。

### 検索・並び替え・絞り込み
* **検索** ― 上部の入力欄に名前の一部を入力して<span style="color: #00b0f0">検索</span>を押すと、名前に入力した文字を含むものだけを表示します。
* **並び替え** ― 「最終更新日 新しい順」「最終更新日 古い順」「名前順 Z-A」「名前順 A-Z」から選択できます。
* **絞り込み** ― 「非表示のモデルを表示しない」「非表示にしたモデルも表示する」「非表示にしたモデルのみ表示する」から選択できます。

### 一覧に表示しない（非表示にする）
警告が表示されている項目には、<span style="color: #00b0f0">非表示にする</span>ボタンが表示されます。押すと、その `.prefab` は非表示の扱いになり、一覧やセットアップタブ・アップロードタブのリストに表示されなくなります。
表示不要な衣装やアクセサリーなどが一覧に表示される場合は、この機能をお使いください。

非表示にしたものは、絞り込みを「非表示にしたモデルも表示する」に変更すると確認でき、<span style="color: #00b0f0">リストに表示</span>ボタンで元に戻すことができます。

:::note
非表示にしても、プレハブ自体はプロジェクトから削除されません。
:::

### 名前の変更・コピー・削除
各項目の右側にあるボタンから、以下の操作ができます。

| ボタン | 内容 |
| ---- | ---- |
| ✏（えんぴつ） | プレハブの名前を変更します。 |
| ⧉（コピー） | プレハブを複製します。複製後、新しい名前を入力する画面が表示されます。改変前のアバターを残しておきたい場合などにご利用ください。 |
| 🗑（ゴミ箱） | プレハブを削除します。 |

:::danger
削除したプレハブは Unity のプロジェクトからも削除されます。元に戻すことはできませんのでご注意ください。
:::

## EA Library（ツール内ガイド）
* * *
右側の「EA Library」には、ツールの使い方やシェーダー、拡張機能、アップロードについての記事があります。分からないことがあれば、ここで調べてみてください。

* 上部の入力欄で記事を検索できます。
* ドロップダウンからタグで記事を絞り込むことができます。
* 記事を選択すると内容が表示されます。戻るボタンで一覧に戻ります。

「モデルの管理」の右上にある `>` ボタンを押すと EA Library を閉じて、モデルの一覧を広く表示できます。もう一度押すと再び開きます。開閉の状態は保存されます。

## 設定
* * *
左下の「設定」では、以下の設定や操作を行うことができます。

### 言語
EAUploader の表示言語を「English」「日本語」「한국어」から変更できます。
言語を変更すると確認のメッセージが表示され、<span style="color: #00b0f0">はい</span>を押すと VRChat SDK の再読み込みが行われて表示が切り替わります。

### テーマ
EAUploader の配色を「ライト」と「ダーク」から選択できます。

:::caution
テーマは試験的な機能です。一部の表示が見づらくなる場合があります。
:::

### バージョン
現在導入されている EAUploader のバージョンが表示されます。お問い合わせの際はバージョンもあわせてお知らせください。

### ログレポートを表示
<span style="color: #00b0f0">ログレポートを表示</span>ボタンを押すと、EAUploader のログファイルが保存されているフォルダ（プロジェクトフォルダ直下の `EAUploaderLog`）を開きます。
不具合を報告する際に、ログファイルを添付していただけると原因の調査がスムーズになります。

:::note
以前のバージョンにあった「フィードバックを送信」機能と、ログの自動送信機能は現在停止しています。ご意見や不具合の報告は [Discord](https://discord.gg/yYFru7brra) 又は [GitHub](https://github.com/Project-EAUploader/EAUploader-for-VRChat/issues) までお願いします。
:::

### Unityを終了する
<span style="color: #00b0f0">Unityを終了する</span>ボタンを押すと、確認の後に Unity を終了します。
