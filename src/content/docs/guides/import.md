---

**アバター一覧**は、EAUploader を開いたときに最初に表示される画面です。アバターや衣装、アクセサリーのインポート、一覧での管理、ツールの設定を行います。

## EAUploaderでのアイテムの管理
* * *
EAUploader では、インポートしたアバターや衣装（Prefab）を**直接変更しません**。
インポートすると、そのPrefabを元にした EAUploader 専用のコピー（Prefab Variant）を次のフォルダに作成し、以降はこのコピーだけを編集・アップロードします。

```
Assets/EAUploader/Prefabs/<アイテム名>/<アイテム名>.prefab
```

そのため、EAUploader で名前を変えたり編集ツールで改変したりしても、アバターの配布元から入手した元のデータはそのまま残ります。

:::note
以前のバージョンの EAUploader を使っていたプロジェクトでは、更新後の初回起動時に「EAUploaderは、Prefabを次のフォルダ以下のPrefab Variantとして管理するようになりました」と表示されます。<span style="color: #00b0f0">移行する</span>を押すと、それまで一覧にあったアイテムが新しい管理方法に移行されます。<span style="color: #00b0f0">あとで</span>を押した場合は、次回の起動時に再度確認されます。
:::

## アイテムをインポートする
* * *
### 対応しているファイル形式
| 形式 | 説明 |
| ---- | ---- |
| `.unitypackage` | パッケージ。アバター本体やシェーダー、衣装などがまとめて配布されています。含まれているPrefabがすべて一覧に追加されます。 |
| `.prefab` | プレハブ。このプロジェクトの `Assets` フォルダ内にあるものを選択できます。 |
| `.vrm` | VRMアバター（ver. 0.x のみ）。VRM Converter for VRChat の導入が必要です。詳しくは「[VRMアバターを使う](/guides/vrm/)」を参照してください。 |

:::caution
EAUploader でアップロードできるのは、**VRChat 用に作成されているアバター**です。VRChat 用として販売・配布されているアバターをご用意ください。
:::

### インポート画面から追加する
アバター一覧の上部にある<span style="color: #00b0f0">インポート</span>ボタンを押すと、インポート画面が開きます。

| ボタン | 内容 |
| ---- | ---- |
| インポート | `.prefab` 又は `.unitypackage` を選択してインポートします。 |
| フォルダからインポート | 選択したフォルダ（その中のフォルダも含む）にある `.prefab` と `.unitypackage` をまとめてインポートします。インポートの前に、対象のファイルの一覧が表示されます。 |
| VRMをインポート | `.vrm` ファイルをインポートします。VRM Converter for VRChat を導入している場合のみ使用できます。 |
| シェーダーをインポート | シェーダーを含む `.unitypackage` をインポートします。 |
| 導入済みのシェーダーを確認 | プロジェクトに導入されているシェーダーの一覧を表示します。一部の VRChat 非対応シェーダーは除外して表示しています。 |

`.unitypackage` を選択した場合、Unity のインポート確認画面は表示されず、パッケージの内容がすべてプロジェクトに追加されます。

:::note
`.prefab` を選択する場合は、このプロジェクトの `Assets` フォルダ内にあるものを選んでください。プロジェクトの外にある `.prefab` や、EAUploader の内部フォルダ（`Assets/EAUploader`）にある `.prefab` は選択できません。他のプロジェクトから取り込む場合は `.unitypackage` を使用してください。
既にプロジェクト内にあるアバターを一覧に追加したい場合も、この方法で選択してください。
:::

### ドラッグ＆ドロップで追加する
エクスプローラーからファイルをアバター一覧にドラッグ＆ドロップすることでもインポートできます。
`.unitypackage`、`.prefab` に加えて、VRM Converter for VRChat を導入している場合は `.vrm` もドロップできます。

### インポートした後に行われること
* **シェーダーの確認** ― アバターに設定されているシェーダーがプロジェクト内に無い場合、「シェーダーの問題が見つかりました」というメッセージを表示します。この場合は「[シェーダーが見つからないエラー](/faq/missing_shader/)」を参照してシェーダーを導入してください。
* **ジャンルの設定** ― VRChat 用のアバターは、自動でジャンルが「アバター」になります。アバター以外のPrefab（衣装やアクセサリーなど）がインポートされた場合は、「衣装・アクセサリーの設定」画面が表示されます。それぞれのジャンルを「衣装」「アクセサリー」「その他」から選び、<span style="color: #00b0f0">保存</span>を押してください。チェックを外したものは設定されません。ジャンルは後から編集画面でも変更できます。
* **プレビュー画像の作成** ― 一覧に表示するためのプレビュー画像を作成します。

## アイテムの一覧
* * *
### カードの見方
アイテムはカードで表示されます。カードにはプレビュー画像、名前、最終更新日、付いているタグが表示されます。ピン留めや非表示にしたアイテムには、それぞれのマークが付きます。

アップロードできないアイテムには、次の表示が出ます。

| 表示 | 意味 |
| ---- | ---- |
| 変換が必要です | VRMアバターです。アップロードするには VRChat 用アバターへの変換が必要です。 |
| アップロードできません | VRChat 用のアバターではないか（VRCAvatarDescriptor がない）、必要なシェーダーがプロジェクトにありません。衣装やアクセサリーにもこの表示が出ます。 |

### カードの操作
* カードをクリックすると、そのアイテムの**編集画面**が開きます。
* カードにマウスを重ねると、<span style="color: #00b0f0">編集</span>、<span style="color: #00b0f0">アップロード</span>（ジャンルが「アバター」のもののみ）、<span style="color: #00b0f0">削除</span>のボタンが表示されます。
* カードを右クリックすると、次のメニューが表示されます。

| メニュー | 内容 |
| ---- | ---- |
| ピン留め / ピン留めを解除 | ピン留めしたアイテムは、並び順に関係なく一覧の先頭に表示されます。 |
| 非表示にする / リストに表示 | 非表示にしたアイテムは、通常は一覧に表示されなくなります。 |
| プロジェクトで表示 | Unity の Project ウィンドウでそのPrefabを表示します。 |
| 削除 | アイテムを削除します。 |

### 検索・絞り込み・並び替え
| 機能 | 内容 |
| ---- | ---- |
| 検索 | 「名前やタグで検索」に入力すると、名前又はタグに入力した文字を含むアイテムだけを表示します。入力するとすぐに絞り込まれます。 |
| カテゴリ | 「アバター」「衣装」「アイテム・その他」から表示するジャンルを選べます。複数選択でき、何も選んでいない場合は「すべて」を表示します。 |
| 並び替え | 「最終更新日 新しい順」「最終更新日 古い順」「名前順 Z-A」「名前順 A-Z」から選べます。ピン留めしたアイテムは常に先頭に表示されます。 |
| タグで絞り込み | 選んだタグを**すべて**持つアイテムだけを表示します。ボタンには選んでいるタグの数が表示されます。 |
| 非表示のアイテムも表示 | オンにすると、非表示にしたアイテムも一覧に表示します。 |
| カードの大きさ | スライダーでカードの大きさを変更できます。大きさは保存されます。 |

## タグを管理する
* * *
タグを使うと、アバターや衣装を自由に分類できます（例：「お気に入り」「冬服」「改変済み」）。
アイテムへのタグの付け外しは、編集画面の「アイテム情報」で行います。（[編集画面](/guides/setup/#タグ)）

<span style="color: #00b0f0">タグの設定</span>ボタンを押すと、プロジェクト全体のタグを管理できます。

* **タグを追加** ― 新しいタグ名を入力して追加します。追加するときにグループを選ぶこともできます。
* **グループを追加** ― タグをまとめるグループを作成します。１つのタグは１つのグループにだけ所属できます。
* **削除** ― タグを削除すると、すべてのアイテムからそのタグが外れます。グループを削除しても、グループ内のタグは残ります。

:::note
タグ名とグループ名は 32 文字までです。大文字と小文字は区別されず、大文字・小文字だけが違うタグは同じタグとして扱われます。
:::

## アイテムを削除する
* * *
カードの<span style="color: #00b0f0">削除</span>ボタンや右クリックメニュー、編集画面の<span style="color: #00b0f0">削除</span>から、アイテムを削除できます。

削除を選ぶと確認画面が開き、一緒に削除される関連アセットが検索されます。
EAUploader の管理用コピーに加えて、**インポート元のPrefabや、そのアイテムでしか使われていないマテリアル・テクスチャもまとめて削除されます**。他のアイテムやシーンで使われているアセットは削除されずに残ります。
「削除する内容の詳細」を開くと、実際に削除されるファイルの一覧を確認できます。

:::danger
削除したアイテムやアセットは Unity のプロジェクトからも削除され、元に戻すことはできません。
削除する前に、詳細で削除される内容を確認してください。
:::

## 設定
* * *
アバター一覧の上部にある<span style="color: #00b0f0">設定</span>ボタンから、次の設定を変更できます。

| 項目 | 内容 |
| ---- | ---- |
| 言語 | EAUploader の表示言語を「English」「日本語」「한국어」から選べます。変更すると確認のメッセージが表示され、<span style="color: #00b0f0">はい</span>を押すと VRChat SDK の再読み込みが行われて表示が切り替わります。 |
| テーマ | 配色を「ライト」「ダーク」「パステル」から選べます。テーマは試験的な機能です。 |
| エラーレポートウィンドウを表示する | オフにすると、エラーが発生してもエラーレポートを自動で表示しなくなります。 |
| バージョン | 導入されている EAUploader のバージョンです。お問い合わせの際はバージョンもあわせてお知らせください。 |
| ログレポートを表示 | EAUploader のログファイルが保存されているフォルダ（プロジェクトフォルダ直下の `EAUploaderLog`）を開きます。不具合を報告する際に、ログファイルを添付していただけると原因の調査がスムーズになります。 |

:::note
以前のバージョンにあった「フィードバックを送信」機能と、ログの自動送信機能は現在停止しています。ご意見や不具合の報告は [Discord](https://discord.gg/yYFru7brra) 又は [GitHub](https://github.com/eauploader/EAUploader-for-VRChat/issues) までお願いします。
:::

## Unityを終了する
* * *
アバター一覧の上部にある<span style="color: #00b0f0">Unityを終了する</span>ボタンを押すと、確認の後に Unity を終了します。
