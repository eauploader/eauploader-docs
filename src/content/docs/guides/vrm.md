## VRMとは
* * *
VRM とは、アバターに特化した3Dモデルのファイル形式の一種です。人型アバターの規格の１つで、VRoid Studio などで簡単に作成できます。
VRM アバターは [VRoid Hub](https://hub.vroid.com/) などで入手できるほか、[VRoid Studio](https://vroid.com/studio) を用いてゲームでのキャラづくりのように簡単に作成できます。

VRM のままでは VRChat にアップロードすることができないので、変換する必要があります。
EAUploader では、**VRM Converter for VRChat** を追加で導入することで、VRM アバターを変換してアップロードすることができます。

:::caution[VRMの対応バージョン]
VRM のバージョンは **VRM 0.x** と **VRM 1.x** で大きく仕様が異なります。
VRM Converter for VRChat は **VRM 0.x にのみ対応しており、VRM 1.x には対応していません。** ご注意ください。
:::

## VRM Converter for VRChatを導入する
* * *
VRM Converter for VRChat を、VCC（又は ALCOM）からプロジェクトに追加するか、[配布ページ](https://booth.pm/ja/items/1025226)からダウンロードしてインポートしてください。
EAUploader で VRM を扱うには、VRM Converter for VRChat と、VRM を読み込むためのパッケージ（UniVRM）の両方がプロジェクトに導入されている必要があります。

導入が完了すると、インポート/設定タブの<span style="color: #00b0f0">VRMをインポート</span>ボタンが押せるようになります。

:::note
導入してもボタンが押せない場合は、Unity 上部のメニュー「EAUploader」→「Reload」を実行するか、Unity を再起動してください。
:::

## VRMをインポートする
* * *
インポート/設定タブの<span style="color: #00b0f0">VRMをインポート</span>ボタンを押し、`.vrm` ファイルを選択してください。
「モデルの管理」の一覧に `.vrm` ファイルをドラッグ＆ドロップしてインポートすることもできます。

インポートした VRM は、プロジェクトの `Assets/VRM` フォルダにプレハブとして保存されます。インポートが完了すると、変換ウィンドウが開きます。

:::caution
プロジェクトの `Assets` フォルダ内にある `.vrm` ファイルは選択できません。プロジェクトの外にあるファイルを選択してください。
:::

## VRChat用アバターへ変換する
* * *
変換ウィンドウで各項目を設定し、<span style="color: #00b0f0">変換</span>ボタンを押してください。

| 項目 | 説明 |
| ---- | ---- |
| 肩の高さ | 肩の高さを調整できます。変換したアバターがなで肩になる場合や上がりすぎる場合は調整してください。 |
| アーマチュアの高さ | Armature（アバターの骨格）の高さを変更します。 |
| メッシュを結合 | メッシュを結合して変換します。これによりメッシュが最適化されます。 |
| シェイプキーの法線と接線を使用 | シェイプキー（表情など）の法線と接線の情報を使用します。 |
| Osc Components | 変換時に追加する OSC 関連のコンポーネントを選択します。 |
| 揺れ物（PC用の設定） | VRM の揺れ物（SpringBone）を VRChat 用の揺れ物に変換する方法を選択します。 |
| 揺れパラメータを引き継ぐ（PC用の設定） | VRM の揺れ物のパラメータを、変換後の揺れ物に引き継ぎます。 |
| Quest用（Quest用の設定） | Quest 用のアバターとしてセットアップします。 |

各項目の詳しい内容は、VRM Converter for VRChat の説明もあわせてご確認ください。

### 変換したアバターを再変換する
一度インポートした VRM アバターは、セットアップタブでアバターを選択し、編集ツールに表示される<span style="color: #00b0f0">VRChatアバターに変換</span>ボタンから再び変換ウィンドウを開くことができます。

同じアバターをもう一度変換した場合でも、既にアップロードしたアバターの Blueprint ID は引き継がれます。

## 視点位置を設定する
* * *
:::caution
変換した VRM アバターは視点位置の設定が必要です。
:::

セットアップタブでアバターを選択し、編集ツールから<span style="color: #00b0f0">ビューポイント位置エディタ</span>を開いて視点を調整してください。
使い方は「[セットアップ（アバターの調整）](/guides/setup/#ビューポイント位置エディタ)」を参照してください。

## アップロードする
* * *
変換と視点位置の設定が完了したら、通常のアバターと同じようにアップロードできます。「[アバターのアップロード](/guides/upload/)」を参照してください。

VRM アバターに使用されているシェーダー（MToon など）が Android（Quest）に対応していない場合があります。Android 用にアップロードする場合は、変換時に「Quest用」をオンにしてください。
