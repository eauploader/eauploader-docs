## EAUploaderの起動・表示について
* * *
### EAUploaderのウィンドウが表示されない
Unity 上部のメニューから「EAUploader」→「Open EAUploader」を選択してください。

メニューに「EAUploader」が表示されない場合は、以下を確認してください。

* VCC の Manage Packages で **Easy Avatar Uploader for VRChat** がプロジェクトに追加されているか。
* Unity のバージョンが 2022.3 であるか。
* Unity の Console に赤いエラー（コンパイルエラー）が表示されていないか。他のツールのエラーが原因で、EAUploader が起動できない場合があります。エラーの原因となっているツールを更新又は削除してください。

### 「EAUploaderに問題が発生しました」と表示される
EAUploader の起動中に問題が発生しました。<span style="color: #00b0f0">再起動</span>を押して EAUploader を再起動してください。
再起動しても問題が解決しない場合は、VCC にて EAUploader を一度プロジェクトから削除し、再度加えてください。

### 「エラーレポート」が表示される
Unity でエラーが発生すると、EAUploader のウィンドウ内に「エラーレポート」が表示されます。これは EAUploader 以外のツールや Unity で発生したエラーでも表示されます。

| ボタン | 内容 |
| ---- | ---- |
| 再起動 | EAUploader を再読み込みします。 |
| コピー | エラーの内容と環境情報（EAUploader、Unity のバージョン、導入されているパッケージ）をコピーします。 |
| OK | エラーレポートを閉じます。 |

エラーの内容をもとに解決を試みるか、コミュニティなどで助けを求めてください。質問する際は、<span style="color: #00b0f0">コピー</span>でコピーした内容を貼り付けると、原因が分かりやすくなります。
EAUploader が原因と思われるエラーの場合は、[公式 Discord サーバー](https://discord.gg/yYFru7brra)にて報告してください。

エラーレポートを自動で表示したくない場合は、「このウィンドウを今後表示しない」にチェックを入れてください。アバター一覧の「設定」にある「エラーレポートウィンドウを表示する」から、再び表示するように戻せます。

### 表示がおかしい・一覧が更新されない
Unity 上部のメニューから「EAUploader」→「Reload」を選択して、EAUploader を再読み込みしてください。

### 更新したら「Prefab Variantとして管理するようになりました」と表示された
古いバージョンから更新したときに表示される、新しい管理方法への移行の確認です。<span style="color: #00b0f0">移行する</span>を押してください。詳しくは「[アバターのインポートと管理](/guides/import/#eauploaderでのアイテムの管理)」を参照してください。

## インポートについて
* * *
### インポートしたアバターが一覧に表示されない
* `.unitypackage` にアバターのPrefabが含まれているか確認してください。
* アバター一覧の「非表示のアイテムも表示」をオンにして、非表示になっていないか確認してください。
* カテゴリやタグで絞り込んでいないか確認してください。
* プロジェクトに既にあるPrefabは、自動では一覧に追加されません。「インポート」画面の<span style="color: #00b0f0">インポート</span>からそのPrefabを選択してください。
* メニューの「EAUploader」→「Reload」を実行してください。

### 「Prefabをインポートできません」と表示される
`.prefab` を選ぶ場合は、このプロジェクトの `Assets` フォルダ内にあるものを選択してください。プロジェクトの外にある `.prefab` や、EAUploader の内部フォルダ（`Assets/EAUploader`）にある `.prefab` は選択できません。他のプロジェクトから取り込む場合は `.unitypackage` を使用してください。

### アバターがピンク色になる・シェーダーのエラーが表示される
アバターに必要なシェーダーがプロジェクトにありません。「[シェーダーが見つからないエラー](/faq/missing_shader/)」を参照してください。

### インポートすると「衣装・アクセサリーの設定」が表示される
アバター以外のPrefab（衣装やアクセサリーなど）がインポートされたため、ジャンルの設定を確認しています。それぞれのジャンルを選んで<span style="color: #00b0f0">保存</span>を押してください。ジャンルは後から編集画面でも変更できます。

### 「VRMをインポート」ボタンが押せない
VRM Converter for VRChat が導入されていません。導入方法は「[VRMアバターを使う](/guides/vrm/)」を参照してください。
導入後も押せない場合は、メニューの「EAUploader」→「Reload」を実行するか、Unity を再起動してください。

### VRMファイルをインポートできない
VRM 1.x のファイルには対応していません。VRM 0.x のファイルをご用意ください。
また、プロジェクトの `Assets` フォルダ内にある `.vrm` ファイルは選択できません。

## 編集について
* * *
### 編集ツールのボタンが押せない
選んでいるアイテムでは使えないツールです。ボタンの下に使えない理由が表示されます。
例えば、着せ替え（対応衣装）はジャンルが「アバター」で VRCAvatarDescriptor を持つアイテムでのみ使用できます。

### 着せ替え（対応衣装）に衣装が表示されない
着せ替え（対応衣装）の一覧には、ジャンルが「衣装」又は「アクセサリー」のアイテムが表示されます。衣装をアバター一覧にインポートし、編集画面でジャンルを確認してください。

### 編集ツールで変更した内容を元に戻したい
保存する前であれば、<span style="color: #00b0f0">元に戻す</span>を押すと最後に保存した状態に戻ります。
保存した後でも、インポート元のPrefabは変更されていません。改変前の状態を残しておきたい場合は、編集する前に編集画面の<span style="color: #00b0f0">複製</span>でアイテムを複製しておくことをおすすめします。

## アップロードについて
* * *
### アップロードのボタンが表示されない
アップロードできるのはジャンルが「アバター」のアイテムだけです。編集画面の「アイテム情報」でジャンルを確認してください。

### アップロードできない
アップロードのシートに「このアバターは以下の理由でアップロードできません」と表示されている場合は、表示されている理由を確認してください。

* **VRCAvatarDescriptorがありません** ― VRChat 用のアバターではないか、アバター以外のPrefabです。
* **シェーダーがありません** ― 必要なシェーダーを導入してください。
* **アバターがVRMモデルです** ― 編集画面から VRChat 用アバターへ変換してください。

### 「現在のトラストランクではアバターをアップロードできません」と表示される
アバターをアップロードするには、VRChat のトラストランクが New User 以上である必要があります。
VRChat で過ごし、フレンドを増やすことでランクを上げることができます。又は、VRChat+ に加入（有料）することで即時ランクを上げることができます。

### 「テスト」ができない
テストは、Unity のビルドターゲットが Windows の場合のみ使用できます。

### Quest（Android）をオンにできない
Unity に Android Build Support モジュールが導入されていません。表示されるメッセージの<span style="color: #00b0f0">Download</span>から、又は Unity Hub の「インストール」から、使用している Unity のバージョンに「Android Build Support」モジュールを追加してください。

### アップロードに失敗する
* プロジェクト名やフォルダ名に全角文字が含まれていると、アップロードできない原因となります。半角英数字と記号のみを使用してください。
* 「アップロード失敗」のメッセージに表示されている原因を確認してください。アバターのファイルサイズが大きすぎる場合は、アバターを軽量化してください。
* VRChat SDK のコントロールパネル（メニューの「VRChat SDK」→「Show Control Panel」）で、エラーが表示されていないか確認してください。

### 同じアバターを別のアバターとしてアップロードしたい
アップロードのシートの「Blueprint」から<span style="color: #00b0f0">VRChatとの紐づけを切る</span>を押してください。次回のアップロードでは別のアバターとしてアップロードされます。詳しくは「[アバターのアップロード](/guides/upload/#blueprint)」を参照してください。

着せ替え（対応衣装）で衣装を着せたアバターを別のアバターとしてアップロードしたい場合は、<span style="color: #00b0f0">新しいアバターとして保存</span>を使うと、元のアバターを残したまま別のアバターとして保存できます。

### 自動最適化（AvatarOptimizer）がオンにできない
AAO: Avatar Optimizer が導入されていません。[Booth](https://booth.pm/ja/items/4885109) 又は VCC から導入し、メニューの「EAUploader」→「Reload」を実行してください。

## その他
* * *
### 表示言語を変更したい
アバター一覧の「設定」にある「言語」から変更できます。現在、English、日本語、한국어 に対応しています。

### 削除したアイテムを元に戻したい
削除したアイテムは元に戻せません。削除するとインポート元のPrefabや関連するアセットも削除されるため、もう一度アバターをインポートしてください。
日頃からプロジェクトのバックアップをとるようにしてください。

### ログファイルはどこにありますか？
プロジェクトフォルダ直下の `EAUploaderLog` フォルダに保存されています。アバター一覧の「設定」にある<span style="color: #00b0f0">ログレポートを表示</span>ボタンを押すと、フォルダを開くことができます。

ログファイルは EAUploader の起動ごとに作成され、`2024-04-22-3.log`（2024年4月22日の3回目の起動）のような名前で保存されます。フォルダの容量が 100MB を超えると、古いものから自動で削除されます。

### こまったときは
上記で解決しない場合は、EAUploader 公式 Discord サーバーにご参加ください。 ▷ [https://discord.gg/yYFru7brra](https://discord.gg/yYFru7brra)

Unity や VRChat SDK の問題、購入したアバターやギミック、ツールに関する問題が発生したときは、それぞれの配布元のサポートを受けてください。
