## EAUploader 시작·표시
* * *
### EAUploader 창이 표시되지 않음
Unity 상단 메뉴에서 'EAUploader' → 'Open EAUploader'를 선택하세요.

메뉴에 'EAUploader'가 표시되지 않으면 다음을 확인하세요.

* VCC의 Manage Packages에서 **Easy Avatar Uploader for VRChat**이 프로젝트에 추가되어 있는지.
* Unity 버전이 2022.3인지.
* Unity의 Console에 빨간 오류(컴파일 오류)가 표시되어 있지 않은지. 다른 도구의 오류 때문에 EAUploader가 시작되지 않을 수 있습니다. 오류의 원인이 되는 도구를 업데이트하거나 삭제하세요.

### 'EAUploader에 문제가 발생했습니다'가 표시됨
EAUploader를 시작하는 중에 문제가 발생했습니다. <span style="color: #00b0f0">다시 시작</span>을 눌러 EAUploader를 다시 시작하세요.
다시 시작해도 해결되지 않으면 VCC에서 EAUploader를 프로젝트에서 한 번 삭제한 후 다시 추가하세요.

### '오류 보고'가 표시됨
Unity에서 오류가 발생하면 EAUploader 창 안에 '오류 보고'가 표시됩니다. 이는 EAUploader 이외의 도구나 Unity에서 발생한 오류에도 표시됩니다.

| 버튼 | 내용 |
| ---- | ---- |
| 다시 시작 | EAUploader를 다시 불러옵니다. |
| 복사 | 오류 내용과 환경 정보(EAUploader, Unity 버전, 설치된 패키지)를 복사합니다. |
| OK | 오류 보고를 닫습니다. |

오류 내용을 바탕으로 해결을 시도하거나 커뮤니티 등에 도움을 요청하세요. 질문할 때 <span style="color: #00b0f0">복사</span>로 복사한 내용을 붙여 넣으면 원인을 파악하기 쉬워집니다.
EAUploader가 원인으로 보이는 오류라면 [공식 Discord 서버](https://discord.gg/yYFru7brra)에 보고해 주세요.

오류 보고를 자동으로 표시하고 싶지 않다면 '이 창을 다시 표시하지 않기'에 체크하세요. 아바타 목록 '설정'의 '오류 보고 창 표시'에서 다시 표시하도록 되돌릴 수 있습니다.

### 표시가 이상함·목록이 업데이트되지 않음
Unity 상단 메뉴에서 'EAUploader' → 'Reload'를 선택하여 EAUploader를 다시 불러오세요.

### 업데이트 후 'Prefab Variant로 관리합니다'가 표시됨
오래된 버전에서 업데이트했을 때 표시되는, 새로운 관리 방식으로의 이전 확인입니다. <span style="color: #00b0f0">이전하기</span>를 누르세요. 자세한 내용은 '[아바타 가져오기와 관리](/ko/guides/import/#eauploader의-아이템-관리)'를 참조하세요.

## 가져오기
* * *
### 가져온 아바타가 목록에 표시되지 않음
* `.unitypackage`에 아바타의 Prefab이 포함되어 있는지 확인하세요.
* 아바타 목록의 '숨긴 항목도 표시'를 켜서 숨겨져 있지 않은지 확인하세요.
* 카테고리나 태그로 필터링하고 있지 않은지 확인하세요.
* 프로젝트에 이미 있는 Prefab은 자동으로 목록에 추가되지 않습니다. '인포트' 창의 <span style="color: #00b0f0">인포트</span>에서 해당 Prefab을 선택하세요.
* 메뉴의 'EAUploader' → 'Reload'를 실행하세요.

### 'Cannot import prefab'가 표시됨
`.prefab`을 선택할 때는 이 프로젝트의 `Assets` 폴더 안에 있는 것을 선택하세요. 프로젝트 밖에 있는 `.prefab`이나 EAUploader 내부 폴더(`Assets/EAUploader`)에 있는 `.prefab`은 선택할 수 없습니다. 다른 프로젝트에서 가져오려면 `.unitypackage`를 사용하세요.

### 아바타가 분홍색이 됨·셰이더 오류가 표시됨
아바타에 필요한 셰이더가 프로젝트에 없습니다. '[셰이더를 찾을 수 없음 오류](/ko/faq/missing_shader/)'를 참조하세요.

### 가져오면 '의상 · 액세서리 설정'이 표시됨
아바타가 아닌 Prefab(의상, 액세서리 등)을 가져왔기 때문에 장르 설정을 확인하는 것입니다. 각각의 장르를 고르고 <span style="color: #00b0f0">저장</span>을 누르세요. 장르는 나중에 편집 화면에서도 바꿀 수 있습니다.

### 'VRM을 인포트' 버튼을 누를 수 없음
VRM Converter for VRChat이 설치되어 있지 않습니다. 설치 방법은 '[VRM 아바타 사용하기](/ko/guides/vrm/)'를 참조하세요.
설치 후에도 누를 수 없으면 메뉴의 'EAUploader' → 'Reload'를 실행하거나 Unity를 다시 시작하세요.

### VRM 파일을 가져올 수 없음
VRM 1.x 파일은 지원하지 않습니다. VRM 0.x 파일을 준비하세요.
또한 프로젝트의 `Assets` 폴더 안에 있는 `.vrm` 파일은 선택할 수 없습니다.

## 편집
* * *
### 편집 도구 버튼을 누를 수 없음
선택한 아이템에서는 사용할 수 없는 도구입니다. 버튼 아래에 사용할 수 없는 이유가 표시됩니다.
예를 들어 옷 갈아입히기(대응 의상)는 장르가 '아바타'이고 VRCAvatarDescriptor를 가진 아이템에서만 사용할 수 있습니다.

### 옷 갈아입히기(대응 의상)에 의상이 표시되지 않음
옷 갈아입히기(대응 의상) 목록에는 장르가 '의상' 또는 '액세서리'인 아이템이 표시됩니다. 의상을 아바타 목록에 가져오고 편집 화면에서 장르를 확인하세요.

### 편집 도구로 바꾼 내용을 되돌리고 싶음
저장하기 전이라면 <span style="color: #00b0f0">되돌리기</span>를 누르면 마지막으로 저장한 상태로 돌아갑니다.
저장한 후에도 가져온 원본 Prefab은 바뀌지 않았습니다. 개변 전 상태를 남겨 두고 싶다면 편집하기 전에 편집 화면의 <span style="color: #00b0f0">복제</span>로 아이템을 복제해 두는 것을 추천합니다.

## 업로드
* * *
### 업로드 버튼이 표시되지 않음
업로드할 수 있는 것은 장르가 '아바타'인 아이템뿐입니다. 편집 화면의 '항목 정보'에서 장르를 확인하세요.

### 업로드할 수 없음
업로드 시트에 '이 아바타는 다음 이유로 업로드할 수 없습니다'가 표시되면 표시된 이유를 확인하세요.

* **VRCAvatarDescriptor가 없습니다** ― VRChat용 아바타가 아니거나 아바타가 아닌 Prefab입니다.
* **쉐이더가 없습니다** ― 필요한 셰이더를 설치하세요.
* **아바타는 VRM 모델입니다** ― 편집 화면에서 VRChat용 아바타로 변환하세요.

### '현재 트러스트 랭크로는 아바타를 업로드할 수 없습니다'가 표시됨
아바타를 업로드하려면 VRChat의 트러스트 랭크가 New User 이상이어야 합니다.
VRChat에서 시간을 보내고 친구를 늘려 랭크를 올릴 수 있습니다. 또는 VRChat+에 가입(유료)하면 즉시 랭크를 올릴 수 있습니다.

### '테스트'를 할 수 없음
테스트는 Unity의 빌드 타겟이 Windows인 경우에만 사용할 수 있습니다.

### Quest(Android)를 켤 수 없음
Unity에 Android Build Support 모듈이 설치되어 있지 않습니다. 표시되는 메시지의 <span style="color: #00b0f0">Download</span> 또는 Unity Hub의 '설치'에서 사용 중인 Unity 버전에 'Android Build Support' 모듈을 추가하세요.

### 업로드에 실패함
* 프로젝트 이름이나 폴더 이름에 전각 문자가 포함되어 있으면 업로드할 수 없는 원인이 됩니다. 알파벳, 숫자, 기호만 사용하세요.
* '업로드 실패' 메시지에 표시된 원인을 확인하세요. 아바타 파일 크기가 너무 크면 아바타를 경량화하세요.
* VRChat SDK의 컨트롤 패널(메뉴의 'VRChat SDK' → 'Show Control Panel')에 오류가 표시되어 있지 않은지 확인하세요.

### 같은 아바타를 별도의 아바타로 업로드하고 싶음
업로드 시트의 'Blueprint'에서 <span style="color: #00b0f0">VRChat과의 연결 끊기</span>를 누르세요. 다음 업로드에서는 별도의 아바타로 업로드됩니다. 자세한 내용은 '[아바타 업로드](/ko/guides/upload/#blueprint)'를 참조하세요.

옷 갈아입히기(대응 의상)로 의상을 입힌 아바타를 별도의 아바타로 업로드하고 싶다면 <span style="color: #00b0f0">새 아바타로 저장</span>을 사용하면 원래 아바타를 남긴 채 별도의 아바타로 저장할 수 있습니다.

### 자동 최적화(AvatarOptimizer)를 켤 수 없음
AAO: Avatar Optimizer가 설치되어 있지 않습니다. [Booth](https://booth.pm/ja/items/4885109) 또는 VCC에서 설치하고 메뉴의 'EAUploader' → 'Reload'를 실행하세요.

## 기타
* * *
### 표시 언어를 바꾸고 싶음
아바타 목록 '설정'의 '언어'에서 바꿀 수 있습니다. 현재 English, 日本語, 한국어를 지원합니다.

### 삭제한 아이템을 되돌리고 싶음
삭제한 아이템은 되돌릴 수 없습니다. 삭제하면 가져온 원본 Prefab과 관련 에셋도 삭제되므로 아바타를 다시 가져오세요.
평소에 프로젝트를 백업해 두세요.

### 로그 파일은 어디에 있나요?
프로젝트 폴더 바로 아래의 `EAUploaderLog` 폴더에 저장됩니다. 아바타 목록 '설정'의 <span style="color: #00b0f0">로그 보고서 열기</span> 버튼을 누르면 폴더를 열 수 있습니다.

로그 파일은 EAUploader를 시작할 때마다 만들어지며, `2024-04-22-3.log`(2024년 4월 22일의 세 번째 시작)와 같은 이름으로 저장됩니다. 폴더 용량이 100MB를 넘으면 오래된 것부터 자동으로 삭제됩니다.

### 문제가 해결되지 않을 때
위 내용으로 해결되지 않으면 EAUploader 공식 Discord 서버에 참여해 주세요. ▷ [https://discord.gg/yYFru7brra](https://discord.gg/yYFru7brra)

Unity나 VRChat SDK의 문제, 구매한 아바타나 기믹, 도구에 관한 문제가 발생했을 때는 각 배포처의 지원을 받으세요.
