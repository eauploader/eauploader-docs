## EAUploader 열기
* * *
EAUploader가 프로젝트에 추가되어 있으면 Unity를 시작할 때 자동으로 창이 열립니다.

창을 닫은 경우에는 Unity 상단 메뉴에서 <span style="color: #00b0f0">EAUploader</span> → <span style="color: #00b0f0">Open EAUploader</span>를 선택하면 다시 열 수 있습니다.

:::note
Unity를 시작한 직후나 스크립트를 불러오는 중에는 창이 열릴 때까지 시간이 조금 걸립니다.
Unity 오른쪽 아래의 로딩 표시가 사라질 때까지 기다려 주세요.
:::

## 세 가지 화면
* * *
EAUploader는 '아바타 목록', '편집 화면', '업로드'의 세 가지 화면으로 구성됩니다.

```
아바타 목록 ──(카드 클릭)──▶ 편집 화면 ──(업로드로 이동)──▶ 업로드
     ▲                         │ ▲                            │
     └──────(목록으로 돌아가기)──┘ └──────(편집으로 돌아가기)────┘
```

| 화면 | 할 수 있는 것 |
| ---- | ---- |
| **아바타 목록** | 처음 표시되는 화면입니다. 아바타, 의상, 액세서리를 카드로 표시합니다. 가져오기, 검색과 필터, 태그 관리, 설정은 여기에서 합니다. |
| **편집 화면** | 선택한 아이템을 3D로 확인하면서 이름이나 태그 등의 정보를 편집하거나 편집 도구로 개변합니다. |
| **업로드** | 편집 화면 오른쪽에 시트로 열립니다. VRChat 로그인, 아바타 정보 설정, 테스트, 업로드를 합니다. 업로드할 수 있는 것은 장르가 '아바타'인 아이템뿐입니다. |

각 화면의 자세한 사용 방법은 다음 페이지를 참조하세요.

- [아바타 가져오기와 관리](/ko/guides/import/)(아바타 목록)
- [편집 화면](/ko/guides/setup/)
- [편집 도구](/ko/guides/edit_tools/)
- [아바타 업로드](/ko/guides/upload/)

## 기본 작업 흐름
* * *
1. **아바타 목록**의 <span style="color: #00b0f0">인포트</span>에서 아바타를 가져옵니다.
2. 셰이더를 찾을 수 없다는 오류가 표시되면 필요한 셰이더를 설치합니다.([셰이더를 찾을 수 없는 오류](/ko/faq/missing_shader/))
3. 아바타 카드를 클릭하여 **편집 화면**을 열고 '업로드 가능'이 표시되는지 확인합니다. 필요하면 편집 도구로 조정합니다.
4. <span style="color: #00b0f0">업로드로 이동</span>으로 **업로드** 시트를 열고, VRChat에 로그인하여 업로드합니다.

## 도움말 버튼
* * *
화면 곳곳에 있는 <span style="color: #00b0f0">도움말</span> 버튼을 누르면 해당 항목의 설명이 표시됩니다.
모르는 항목이 있으면 먼저 도움말을 확인하세요.

## 창 안의 메시지
* * *
확인 메시지, 설정, 도움말 등은 EAUploader 창 안에 겹쳐서 표시됩니다(모달).
복사나 저장이 완료되면 화면 가장자리에 짧은 알림이 표시됩니다.

## Unity 메뉴
* * *
Unity 상단의 'EAUploader' 메뉴에서 다음 작업을 할 수 있습니다.

| 메뉴 | 내용 |
| ---- | ---- |
| Open EAUploader | EAUploader 창을 엽니다. |
| Reload | 아이템 목록, 편집 도구, 연계 도구(VRM Converter, AvatarOptimizer, Modular Avatar)의 설치 상태를 다시 불러옵니다. 표시가 이상하거나 연계 도구를 설치한 후에 시도해 보세요. |
| ViewpointPositionEditor | 선택한 아바타의 뷰포인트 위치 에디터를 엽니다. |
| Edit Tools | 셰이프 키 편집, 텍스처 편집, 옷 갈아입히기(대응 의상)를 엽니다.(일반적으로는 편집 화면에서 엽니다) |

## 작업 저장에 대해
* * *
EAUploader에서의 작업은 Unity에 변경을 가하는 것입니다. Unity는 일반적으로 작업 상태를 유지하므로 종료할 때 저장할 필요가 없습니다.

단, EAUploader에서 삭제한 아이템은 Unity에서도 삭제됩니다. 삭제할 때는 주의하세요.
