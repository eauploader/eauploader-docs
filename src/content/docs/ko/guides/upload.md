---
title: '아바타 업로드'
description: '업로드 사용 방법'
---

업로드는 편집 화면 오른쪽에 열리는 'VRChat에 업로드' 시트에서 합니다.
편집 화면의 <span style="color: #00b0f0">업로드로 이동</span> 버튼 또는 아바타 목록 카드의 <span style="color: #00b0f0">업로드</span> 버튼으로 엽니다. <span style="color: #00b0f0">편집으로 돌아가기</span>를 누르면 시트가 닫힙니다.

## 업로드하기 전에
* * *
아바타를 업로드하려면 다음 조건을 만족해야 합니다.

* 아이템의 장르가 '아바타'일 것
* 아바타에 VRCAvatarDescriptor가 있고 필요한 셰이더가 프로젝트에 설치되어 있을 것(편집 화면에 '업로드 가능'이 표시될 것)
* VRChat 계정에 로그인되어 있을 것
* VRChat의 트러스트 랭크가 **New User** 이상일 것

조건을 만족하지 않으면 '이 아바타는 다음 이유로 업로드할 수 없습니다'와 함께 이유가 표시됩니다.

:::note
트러스트 랭크가 부족하면 VRChat에서 시간을 보내고 친구를 늘려 랭크를 올릴 수 있습니다. 또는 VRChat+에 가입(유료)하면 즉시 랭크를 올릴 수 있습니다.
:::

## VRChat에 로그인
* * *
VRChat에 로그인하지 않은 경우 <span style="color: #00b0f0">로그인</span> 버튼이 표시됩니다.
버튼을 누르면 VRChat SDK의 컨트롤 패널이 열리므로 VRChat 계정으로 로그인하세요.

로그인하면 로그인한 사용자 이름과 아바타 업로드 권한이 있는지가 표시됩니다.

## VRChat에서의 표시 설정하기
* * *
| 항목 | 설명 |
| ---- | ---- |
| 썸네일 | 아바타의 썸네일입니다. 기본적으로 EAUploader의 미리보기 이미지가 사용됩니다. <span style="color: #00b0f0">썸네일 변경</span>에서 이미지 파일(png, jpg)을 골라 바꿀 수 있습니다. 바꿀 때 'EAUplaoder의 아바타 목록의 썸네일에도 적용할 수 있나요?'라고 표시되므로, 목록의 미리보기 이미지도 바꾸고 싶다면 <span style="color: #00b0f0">예</span>를 고르세요. 썸네일 옆의 버튼으로 미리보기 이미지로 되돌릴 수 있습니다. |
| 아바타 이름 | VRChat에 표시되는 아바타 이름입니다. **이 항목은 필수입니다.** |
| 아바타 설명 | 아바타의 설명란입니다. 자신을 위한 메모로 사용합니다. 입력하지 않아도 업로드할 수 있습니다. |
| 공개 설정 | 비공개: 자신만 사용할 수 있습니다.<br />공개: 누구나 사용할 수 있도록 공개됩니다. |

:::danger
인터넷에서 배포·판매되는 아바타는 기본적으로 공개(Public)로 하는 것이 금지되어 있습니다.
직접 만든 아바타가 아니라면 공개로 업로드하지 마세요.
:::

### 콘텐츠 설정
아바타 내용에 맞춰 태그를 설정하세요. '성적인 시각적 표현', '성인을 대상으로 한 말과 표현', '폭력적인 표현', '과도한 출혈 및 피', '극한의 호러' 중에서 고를 수 있습니다.
해당하는 아바타에 태그를 붙이지 않고 사용하면 위반이 될 수 있습니다.

## 이미 업로드한 아바타의 경우
* * *
이미 VRChat에 업로드한 적이 있는 아바타는 VRChat의 정보를 불러와 각 항목에 입력됩니다. 또한 'VRChat Information'으로 제작자, 업로드 날짜, 업데이트 횟수가 표시됩니다.

### 아바타 정보만 업데이트하기
이름, 설명, 공개 설정, 콘텐츠 설정, 썸네일을 바꾸면 <span style="color: #00b0f0">저장</span>과 <span style="color: #00b0f0">포기</span> 버튼이 표시됩니다.

* <span style="color: #00b0f0">저장</span> ― 아바타를 다시 업로드하지 않고 VRChat의 아바타 정보만 업데이트합니다.
* <span style="color: #00b0f0">포기</span> ― 변경을 취소하고 VRChat의 정보로 되돌립니다.

### Blueprint
Blueprint(Blueprint ID)는 VRChat에서 아바타에 할당된 개별 ID입니다. 같은 Blueprint ID를 가진 아바타를 업로드하면 VRChat의 아바타가 덮어쓰기(업데이트)됩니다.

* <span style="color: #00b0f0">복사</span> ― Blueprint ID를 클립보드에 복사합니다.
* <span style="color: #00b0f0">VRChat과의 연결 끊기</span> ― 아바타에 새 ID를 할당합니다. 다음 업로드에서는 VRChat의 기존 아바타를 덮어쓰지 않고 별도의 아바타로 업로드됩니다.

:::danger
Blueprint ID를 다른 사람에게 공개하지 마세요. 이 ID를 사용하면 VRChat의 아바타를 업데이트하거나 삭제할 수 있으므로, 다른 사람에게 공개하면 아바타 데이터를 도난당할 수 있습니다.
:::

## 플랫폼 고르기
* * *
'플랫폼'에서 업로드할 대상을 고릅니다.

| 플랫폼 | 설명 |
| ---- | ---- |
| Windows | PC용 아바타입니다. 항상 업로드됩니다. |
| Quest (Android) | 켜면 Quest 단독이나 스마트폰용 아바타도 함께 업로드합니다. Unity에 Android Build Support 모듈이 필요합니다. |
| iOS | 켜면 iOS용 아바타도 함께 업로드합니다. iOS 업로드가 허용된 계정에서만 표시됩니다. Unity에 iOS Build Support 모듈이 필요합니다. |

여러 플랫폼을 고르면 업로드 중 빌드 타겟이 전환되고 완료 후 Windows로 복원됩니다. 시간이 걸릴 수 있습니다.

필요한 모듈이 설치되지 않은 상태에서 켜면 모듈 다운로드를 안내하는 메시지가 표시됩니다. Unity Hub의 '설치'에서 사용 중인 Unity 버전에 모듈을 추가하세요.

:::caution
Quest(Android)용으로 업로드하는 아바타는 Quest 대응 아바타여야 합니다. 아바타 배포처에서 Quest 대응 여부를 확인하세요.
:::

## 아바타 성능
* * *
VRChat에서는 아바타의 부하에 따라 5단계의 평가가 매겨집니다. 플레이어는 이 평가에 따라 아바타를 숨길 수 있으며, 부하가 높은 아바타는 일부 플레이어에게 표시되지 않을 수 있습니다.

가벼운 순서대로 **Excellent - Good - Medium - Poor - Very Poor**로 평가됩니다.
종합 평가가 표시되며, <span style="color: #00b0f0">자세히 보기</span>를 누르면 폴리곤 수, 머티리얼 슬롯, PhysBone 컴포넌트 등 항목별 평가를 확인할 수 있습니다.

VRChat은 Good까지 최적화/경량화할 것을 권장하지만, PC용 아바타는 Very Poor여도 문제없이 업로드할 수 있습니다.

:::note
EAUploader에 표시되는 성능은 PC(Windows)용 기준으로 계산한 것입니다. Android용 아바타에는 여러 제약이 있으며, 제한을 넘는 아바타는 Android(Quest / 스마트폰) 사용자에게 표시되지 않습니다.
:::

## 아바타 최적화
* * *
별도 도구 'AAO: Avatar Optimizer(by anatawa12)'를 프로젝트에 설치하면 <span style="color: #00b0f0">자동 아바타 최적화(AvatarOptimizer)</span>를 사용할 수 있습니다.

켜면 아바타에 AvatarOptimizer의 자동 최적화 컴포넌트 'Trace And Optimize'가 추가되어, 업로드할 때 아바타의 모습을 바꾸지 않고 비파괴로 최적화됩니다. 끄면 컴포넌트를 삭제합니다.

* 최적화 결과는 빌드해야 알 수 있습니다. 아바타 성능에는 최적화 후의 결과가 반영되지 않습니다.
* 최적화 설정은 EAUploader에서 바꿀 수 없습니다. 설정을 바꾸거나 다른 최적화 기능을 사용하려면 Unity 에디터에서 해야 합니다.
* AvatarOptimizer가 설치되지 않은 상태에서 켜면 설치를 안내하는 메시지가 표시됩니다. AvatarOptimizer는 [Booth](https://booth.pm/ja/items/4885109) 또는 VCC에서 설치할 수 있습니다. 설치 후에는 메뉴의 'EAUploader' → 'Reload'를 실행하세요.

## 테스트하기
* * *
시트 아래쪽의 <span style="color: #00b0f0">테스트</span>를 누르면 로컬(자신의 PC)에서 아바타를 빌드하여 VRChat에서 사용할 수 있게 합니다. 업로드하지 않고 아바타의 동작을 확인할 수 있습니다.

테스트로 빌드한 아바타는 VRChat에 업로드되지 않습니다. 따라서 다른 플레이어에게는 아바타가 보이지 않습니다.
테스트로 빌드한 아바타는 VRChat 앱의 아바타 메뉴 안 'Other'에서 고를 수 있습니다.

:::note
테스트는 Unity의 빌드 타겟이 Windows인 경우에만 사용할 수 있습니다.
:::

## 업로드하기
* * *
1. 아바타 이름을 입력합니다.
2. '위의 설정이 올바르며, VRChat에 아바타를 업로드할 수 있음을 확인했습니다.'에 체크합니다.
3. <span style="color: #00b0f0">업로드</span> 버튼을 누릅니다.

업로드 중에는 진행 상황이 표시됩니다. <span style="color: #00b0f0">업로드 취소</span>로 중지할 수도 있습니다. 업로드가 완료된 아바타는 VRChat에서 사용할 수 있습니다.

:::note
업로드는 아바타의 복사본을 씬에 임시로 만들어서 진행합니다. Modular Avatar나 AvatarOptimizer 같은 비파괴 도구의 처리는 이 복사본에 대해 이루어지므로 EAUploader의 관리용 복사본은 변경되지 않습니다.
:::

### 업로드에 실패하는 경우
업로드에 실패하면 '업로드 실패' 메시지에 원인이 표시됩니다. 아바타 파일 크기가 VRChat의 상한을 넘는 경우 등에는 아바타를 경량화하세요.
또한 오류가 발생하면 '오류 보고'가 표시됩니다. 자세한 내용은 '[자주 묻는 질문과 문제 해결](/ko/faq/troubleshooting/)'을 참조하세요.
