---
title: '편집 도구'
description: 'EAUploader에 기본 탑재된 편집 도구 사용 방법'
---

편집 도구는 편집 화면 왼쪽의 '편집 도구'에서 엽니다. 도구는 EAUploader 창 안에 겹쳐서 표시되며, 편집 화면에서 선택한 아이템에 대해 동작합니다.

## 공통 조작
* * *
뷰포인트 위치 에디터를 제외한 도구는 공통으로 다음과 같은 화면입니다.

| 위치 | 내용 |
| ---- | ---- |
| 위쪽 | 도구 이름, 아이템 이름, 변경이 있을 때는 '저장되지 않은 변경 사항', 오른쪽 위에 <span style="color: #00b0f0">돌아가기</span> 버튼 |
| 왼쪽 | 도구별 설정 |
| 가운데 | 변경을 반영한 미리보기(조작은 편집 화면의 3D 미리보기와 같습니다) |
| 아래쪽 | <span style="color: #00b0f0">되돌리기</span>, <span style="color: #00b0f0">적용</span> 버튼 |

* 변경 사항은 <span style="color: #00b0f0">적용</span>을 누를 때까지 저장되지 않습니다. <span style="color: #00b0f0">되돌리기</span>를 누르면 마지막으로 저장한 상태로 돌아갑니다.
* 저장하지 않고 <span style="color: #00b0f0">돌아가기</span>를 누르면 저장할지 확인하는 메시지가 표시됩니다.
* 변경 사항은 EAUploader의 관리용 복사본에 저장됩니다. 가져온 원본 아바타와 의상, 원본 텍스처·머티리얼은 변경되지 않습니다.
* 도구로 만든 텍스처와 머티리얼은 아이템 폴더(`Assets/EAUploader/Prefabs/<아이템 이름>/`)에 저장됩니다.
* 저장하면 아이템의 미리보기 이미지도 자동으로 다시 만들어집니다.

## 뷰포인트 위치 에디터
* * *
아바타의 시점 위치(VRChat에서 자신의 눈높이가 되는 위치)를 설정합니다. VRCAvatarDescriptor를 가진 아바타에서 사용할 수 있습니다.

1. 왼쪽의 세로·가로 막대를 움직여 시점 위치를 바꿉니다. 이동 중인 위치는 <span style="color: red">빨간 점</span>, 적용된 위치는 <span style="color: green">초록 점</span>으로 표시됩니다.
2. 위쪽의 🔄 버튼을 누르면 아바타를 보는 방향을 반전할 수 있습니다.
3. 오른쪽의 '실제 보기'는 시점 위치에서 본 미리보기입니다. 아바타의 얼굴 안쪽이 보이면 배경이 깨끗하게 보일 때까지 이동하세요. '1:1 (VR)'과 '16:9 (PC)'로 표시 비율을 바꿀 수 있습니다.
4. 위치가 정해지면 <span style="color: #00b0f0">적용</span> 버튼을 누르세요.

:::note
뷰포인트 위치 에디터에는 '저장되지 않은 변경 사항' 확인이 없습니다. <span style="color: #00b0f0">적용</span>을 누르지 않고 <span style="color: #00b0f0">돌아가기</span>를 누르면 움직인 위치는 버려집니다.
:::

## 셰이프 키 편집
* * *
체형이나 얼굴 형태 등 셰이프 키(블렌드 셰이프)의 기본값을 조정하여 저장합니다. 의상에 가려지는 신체 부위를 줄이는 용도로도 쓸 수 있습니다. 셰이프 키를 가진 메시가 있는 아이템에서 사용할 수 있습니다.

| 항목 | 내용 |
| ---- | ---- |
| 메시 | 편집할 메시를 고릅니다. 처음에는 립싱크에 사용되는 메시(없으면 셰이프 키가 가장 많은 메시)가 선택되어 있습니다. |
| 얼굴 보기 / 전신 보기 | 미리보기 카메라를 얼굴 또는 전신에 맞춥니다. |
| 셰이프 키 검색 | 이름으로 셰이프 키를 필터링합니다. |
| 변경한 항목만 표시 | 저장된 값에서 변경한 셰이프 키만 표시합니다. |
| 셰이프 키 목록 | 슬라이더나 숫자로 값을 바꿉니다. 행 오른쪽의 버튼으로 해당 행을 저장된 값으로 되돌릴 수 있습니다. |
| 이 메시 초기화 / 모두 0으로 | 선택한 메시의 셰이프 키를 한꺼번에 되돌리거나 0으로 만듭니다. |

'립싱크', '눈꺼풀' 표시가 붙은 셰이프 키는 VRChat에서 입 움직임이나 눈 깜빡임에 사용됩니다. 기본값을 바꾸면 게임 안에서 올바르게 표시되지 않을 수 있으니 주의하세요.

## 텍스처 편집
* * *
텍스처 색상을 바꾸거나 다른 이미지로 교체합니다. 텍스처를 가진 머티리얼이 있는 아이템에서 사용할 수 있습니다.

1. '머티리얼'에서 편집할 머티리얼을 고릅니다. 이 도구로 만든 머티리얼에는 '편집됨', 아직 적용하지 않은 변경이 있는 것에는 '변경됨'이 표시됩니다.
2. 편집할 텍스처의 종류(메인 텍스처, 그림자 색, 이미션 등)를 고릅니다.
3. '색상 조정'에서 **색조**, **채도**, **밝기**, **대비**, **색조 보정**(곱할 색)을 조정합니다. <span style="color: #00b0f0">이미지 교체...</span>를 누르면 이미지 파일(png, jpg)을 바탕으로 할 수도 있습니다.
4. <span style="color: #00b0f0">적용</span>을 누르면 조정한 텍스처와 그것을 사용하는 머티리얼의 복사본이 만들어져 아이템에 설정됩니다.

* 원본 텍스처와 머티리얼은 변경되지 않습니다. 편집한 복사본은 적용할 때 아이템 폴더에 저장됩니다.
* 편집한 머티리얼을 다시 편집하면 이전 조정값부터 편집을 이어갈 수 있습니다. 조정을 반복해도 화질은 떨어지지 않습니다.
* <span style="color: #00b0f0">조정 초기화</span>로 조정값을 초기값으로 되돌릴 수 있습니다. <span style="color: #00b0f0">원래 머티리얼로 되돌리기</span>를 누르면 편집 전 머티리얼로 돌아갑니다.

## 옷 갈아입히기 (대응 의상)
* * *
아바타에 해당 아바타용으로 만들어진 의상(대응 의상)이나 액세서리를 입힙니다. VRCAvatarDescriptor를 가지고 장르가 '아바타'인 아이템에서 사용할 수 있습니다.
입힐 의상이나 액세서리는 미리 아바타 목록에 가져오고, 장르를 '의상' 또는 '액세서리'로 설정해 두세요.

:::caution
이 도구는 입힐 아바타용으로 만들어진 의상(같은 본 구조·같은 자세)이 대상입니다. 다른 아바타용 의상은 입힐 수 없습니다.
:::

### 화면 보는 법
| 항목 | 내용 |
| ---- | ---- |
| 상태 | Modular Avatar가 설치되어 있는지와 의상 본의 처리 방식이 표시됩니다. |
| 착용 중 | 입힌 의상 목록입니다. 의상별로 표시·숨기기를 전환하거나 <span style="color: #00b0f0">벗기기</span>로 의상을 벗길 수 있습니다. |
| 아바타 파츠 | 아바타에 원래 붙어 있는 옷 등의 파츠입니다. 의상과 함께 표시하고 싶지 않은 것은 꺼 주세요. <span style="color: #00b0f0">표시를 원래대로</span>로 원래 상태로 되돌릴 수 있습니다. |
| 의상 추가 | 장르가 '의상', '액세서리'인 아이템이 표시됩니다. 이름이나 태그로 검색하고 클릭하면 입힐 수 있습니다. |

### 의상 입히기
* 본 구조를 가진 의상은 아바타의 본에 맞춰 입혀집니다.
  * **Modular Avatar가 설치된 경우** ― Modular Avatar 기능으로 의상이 설정되며 아바타의 본 구조는 바뀌지 않습니다.
  * **Modular Avatar가 설치되지 않은 경우** ― 의상의 본은 업로드할 때 만들어지는 복사본 안에서만 아바타의 본에 통합됩니다. 아바타 자체는 바뀌지 않습니다.
* 본 구조가 없는 액세서리는 '부착 위치'(머리, 목, 가슴, 척추, 엉덩이, 손, 발, 아바타 루트 등)를 골라 부착합니다.

### 저장하기
* <span style="color: #00b0f0">적용</span> ― 입힌 상태를 편집 중인 아바타에 저장합니다.
* <span style="color: #00b0f0">새 아바타로 저장</span> ― 입힌 상태를 별도의 아바타로 저장합니다. 원래 아바타는 그대로 남고, 새 아바타는 VRChat에 별도의 아바타로 업로드됩니다.

:::note
의상은 복사해서 입히므로, 입힌 뒤 아바타 목록에서 의상 아이템을 삭제해도 아바타에 입힌 의상은 망가지지 않습니다.
:::
