**편집 화면**에서는 선택한 아이템을 3D로 확인하면서 이름이나 태그 등의 정보를 편집하거나 편집 도구로 개변합니다.
아바타 목록에서 카드를 클릭하거나 카드의 <span style="color: #00b0f0">편집</span> 버튼을 누르면 열립니다.

## 화면 구성
* * *
화면 전체에 아이템의 3D 미리보기가 표시되고, 그 위에 다음 패널이 겹쳐 있습니다.

| 위치 | 내용 |
| ---- | ---- |
| 위쪽 | <span style="color: #00b0f0">목록으로 돌아가기</span> 버튼, 열려 있는 아이템의 이름과 장르 |
| 왼쪽 '편집 도구' | 아이템의 상태와 편집 도구 목록 |
| 오른쪽 '항목 정보' | 썸네일, 이름, 장르, 태그, 메모 등의 정보 |

왼쪽과 오른쪽 패널은 패널 오른쪽 위의 버튼으로 접을 수 있습니다. 접은 패널은 화면 가장자리에 표시되는 버튼으로 다시 열 수 있습니다.

## 3D 미리보기
* * *
| 조작 | 동작 |
| ---- | ---- |
| 왼쪽 클릭한 채로 이동 | 회전 |
| 오른쪽 클릭한 채로 이동 | 이동 |
| 휠 위아래 | 확대/축소 |
| 리셋 버튼 | 표시 초기화 |

## 아이템 상태 확인하기
* * *
'편집 도구' 위쪽에는 아이템의 상태가 표시됩니다.

| 표시 | 의미와 대처 방법 |
| ---- | ---- |
| ✅ 업로드 가능 | 그대로 업로드할 수 있습니다. |
| VRCAvatarDescriptor가 없습니다 | VRChat용 아바타가 아닙니다. 의상이나 액세서리라면 문제없습니다. VRChat용으로 배포된 아바타라면 올바른 Prefab을 선택했는지 확인하세요. |
| 쉐이더가 없습니다 | 아이템에 필요한 셰이더가 프로젝트에 없습니다. '[셰이더를 찾을 수 없는 오류](/ko/faq/missing_shader/)'를 참조하세요. |
| VRM 아바타를 VRChat 아바타로 변환해야합니다 | VRM 아바타입니다. <span style="color: #00b0f0">VRChat 아바타로 변환</span> 버튼으로 변환하세요. 자세한 내용은 '[VRM 아바타 사용하기](/ko/guides/vrm/)'를 참조하세요. |
| This avatar is a converted VRM, Viewpoint Position may need to be adjusted. | VRM에서 변환한 아바타입니다. 시점 위치 조정이 필요할 수 있습니다. '[뷰포인트 위치 에디터](/ko/guides/edit_tools/#뷰포인트-위치-에디터)'로 시점 위치를 확인하세요. |

## 편집 도구 사용하기
* * *
'편집 도구'에는 아이템을 조정하는 도구가 목록으로 표시됩니다. 도구 이름 버튼을 누르면 도구가 EAUploader 창 안에 열립니다.

버튼 오른쪽의 ▼를 누르면 도구의 설명, 버전, 제작자가 표시됩니다. 선택한 아이템에서 사용할 수 없는 도구는 버튼을 누를 수 없는 상태가 되고, 사용할 수 없는 이유가 표시됩니다.

EAUploader에는 다음 편집 도구가 기본으로 탑재되어 있습니다. 사용 방법은 '[편집 도구](/ko/guides/edit_tools/)'를 참조하세요.

| 도구 | 내용 |
| ---- | ---- |
| 뷰포인트 위치 에디터 | 아바타의 시점 위치를 설정합니다. |
| 셰이프 키 편집 | 체형이나 표정 등 셰이프 키의 기본값을 조정합니다. |
| 텍스처 편집 | 텍스처 색상을 바꾸거나 다른 이미지로 교체합니다. |
| 옷 갈아입히기 (대응 의상) | 해당 아바타용으로 만들어진 의상이나 액세서리를 입힙니다. |

EAUploader에 대응하는 확장 기능을 설치하면 여기에 도구가 추가됩니다.

## 항목 정보 편집하기
* * *
오른쪽 '항목 정보'에서 아이템의 정보를 편집할 수 있습니다. 변경 사항은 바로 저장됩니다.

### 썸네일
아이템의 썸네일(목록에 표시되는 미리보기 이미지)입니다.

* 🔄 버튼(미리보기 재생성하기) ― 현재 아이템의 모습으로 미리보기 이미지를 다시 만듭니다. 편집 도구로 모습을 바꾼 뒤 등에 사용하세요.
* <span style="color: #00b0f0">썸네일 변경</span> ― 이미지 파일(png, jpg)을 선택하여 썸네일을 교체합니다.

### 이름
아이템의 이름입니다. 입력란에서 포커스가 벗어나거나 Enter 키를 누르면 반영됩니다.
이름을 바꾸면 EAUploader 관리용 복사본의 파일 이름이 바뀝니다. 가져온 원본 Prefab의 이름은 바뀌지 않습니다.

### 장르
'아바타', '의상', '액세서리', '기타' 중에서 고릅니다. 업로드할 수 있는 것은 장르가 '아바타'인 아이템뿐입니다.
장르는 아바타 목록의 카테고리 필터와 옷 갈아입히기(대응 의상)에서 입힐 의상 목록에 사용됩니다.

### 태그
입력란에 입력하면 기존 태그 후보가 표시됩니다. 후보를 선택하거나 Enter 키를 누르면 태그가 추가됩니다. 아직 없는 태그 이름이면 <span style="color: #00b0f0">Create new tag</span>로 추가할 수 있습니다.
추가한 태그의 ×를 누르면 해당 아이템에서 태그를 뗄 수 있습니다.

태그 이름은 32자까지입니다. 프로젝트 전체의 태그와 그룹은 아바타 목록의 <span style="color: #00b0f0">태그 설정</span>에서 관리할 수 있습니다.

### 메모
자유롭게 메모를 남길 수 있습니다. 입력란에서 포커스가 벗어나면 저장됩니다.

### 고정·목록에서 숨기기
* **고정** ― 켜면 아바타 목록 맨 앞에 표시됩니다.
* **목록에서 숨기기** ― 켜면 아바타 목록에 표시되지 않습니다('숨긴 항목도 표시'를 켜면 확인할 수 있습니다).

고정과 숨기기는 동시에 설정할 수 없습니다.

### 상세 정보
최종 업데이트 날짜, 아바타 높이(시점 높이), Blueprint ID, 저장 위치(EAUploader 관리용 복사본의 경로)가 표시됩니다.
Blueprint ID는 가려진 상태로 표시되며 👁 버튼으로 표시를 전환할 수 있습니다. Blueprint ID와 저장 위치는 복사 버튼으로 클립보드에 복사할 수 있습니다.

:::danger
Blueprint ID를 다른 사람에게 공개하지 마세요. 자세한 내용은 '[아바타 업로드](/ko/guides/upload/#blueprint)'를 참조하세요.
:::

### 복제·삭제
* <span style="color: #00b0f0">복제</span> ― 아이템을 하나 더 만들고 복제한 쪽을 엽니다. 개변 전 상태를 남겨 두고 싶을 때나 같은 아바타로 다른 개변을 하고 싶을 때 사용하세요. 복제한 것도 가져온 원본 Prefab을 바탕으로 한 관리용 복사본이므로 원본 데이터에는 영향이 없습니다.
* <span style="color: #00b0f0">삭제</span> ― 아이템을 삭제합니다. 자세한 내용은 '[아이템 삭제하기](/ko/guides/import/#아이템-삭제하기)'를 참조하세요.

## 업로드로 이동하기
* * *
장르가 '아바타'인 아이템에서는 항목 정보 아래쪽에 <span style="color: #00b0f0">업로드로 이동</span> 버튼이 표시됩니다. 누르면 화면 오른쪽에 업로드 시트가 열립니다.
사용 방법은 '[아바타 업로드](/ko/guides/upload/)'를 참조하세요.
