**아바타 목록**은 EAUploader를 열었을 때 처음 표시되는 화면입니다. 아바타, 의상, 액세서리를 가져오고, 목록에서 관리하고, 도구를 설정합니다.

## EAUploader의 아이템 관리
* * *
EAUploader는 가져온 아바타나 의상(Prefab)을 **직접 변경하지 않습니다**.
가져오면 해당 Prefab을 바탕으로 한 EAUploader 전용 복사본(Prefab Variant)을 다음 폴더에 만들고, 이후에는 이 복사본만 편집하고 업로드합니다.

```
Assets/EAUploader/Prefabs/<아이템 이름>/<아이템 이름>.prefab
```

따라서 EAUploader에서 이름을 바꾸거나 편집 도구로 개변하더라도 아바타 배포처에서 받은 원본 데이터는 그대로 남습니다.

:::note
이전 버전의 EAUploader를 사용하던 프로젝트에서는 업데이트 후 처음 시작할 때 'EAUploader는 이제 Prefab을 다음 폴더 아래의 Prefab Variant로 관리합니다'라는 메시지가 표시됩니다. <span style="color: #00b0f0">이전하기</span>를 누르면 기존에 목록에 있던 아이템이 새로운 관리 방식으로 이전됩니다. <span style="color: #00b0f0">나중에</span>를 누르면 다음에 시작할 때 다시 확인합니다.
:::

## 아이템 가져오기
* * *
### 지원하는 파일 형식
| 형식 | 설명 |
| ---- | ---- |
| `.unitypackage` | 패키지. 아바타 본체, 셰이더, 의상 등이 함께 배포됩니다. 포함된 Prefab이 모두 목록에 추가됩니다. |
| `.prefab` | 프리팹. 이 프로젝트의 `Assets` 폴더 안에 있는 것을 선택할 수 있습니다. |
| `.vrm` | VRM 아바타(ver. 0.x만). VRM Converter for VRChat이 필요합니다. 자세한 내용은 '[VRM 아바타 사용하기](/ko/guides/vrm/)'를 참조하세요. |

:::caution
EAUploader로 업로드할 수 있는 것은 **VRChat용으로 만들어진 아바타**입니다. VRChat용으로 판매·배포되는 아바타를 준비하세요.
:::

### 인포트 창에서 추가하기
아바타 목록 위쪽의 <span style="color: #00b0f0">인포트</span> 버튼을 누르면 인포트 창이 열립니다.

| 버튼 | 내용 |
| ---- | ---- |
| 인포트 | `.prefab` 또는 `.unitypackage`를 선택하여 가져옵니다. |
| 폴더에서 인포트 | 선택한 폴더(하위 폴더 포함)에 있는 `.prefab`과 `.unitypackage`를 한꺼번에 가져옵니다. 가져오기 전에 대상 파일 목록이 표시됩니다. |
| VRM을 인포트 | `.vrm` 파일을 가져옵니다. VRM Converter for VRChat을 설치한 경우에만 사용할 수 있습니다. |
| 쉐이더를 인포트 | 셰이더가 포함된 `.unitypackage`를 가져옵니다. |
| 기존 쉐이더 확인 | 프로젝트에 설치된 셰이더 목록을 표시합니다. 일부 VRChat 비대응 셰이더는 제외하고 표시합니다. |

`.unitypackage`를 선택하면 Unity의 가져오기 확인 창이 표시되지 않고 패키지 내용이 모두 프로젝트에 추가됩니다.

:::note
`.prefab`을 선택할 때는 이 프로젝트의 `Assets` 폴더 안에 있는 것을 선택하세요. 프로젝트 밖에 있는 `.prefab`이나 EAUploader 내부 폴더(`Assets/EAUploader`)에 있는 `.prefab`은 선택할 수 없습니다. 다른 프로젝트에서 가져오려면 `.unitypackage`를 사용하세요.
이미 프로젝트 안에 있는 아바타를 목록에 추가하고 싶을 때도 이 방법으로 선택하세요.
:::

### 드래그 앤 드롭으로 추가하기
탐색기에서 파일을 아바타 목록에 드래그 앤 드롭하여 가져올 수도 있습니다.
`.unitypackage`, `.prefab` 외에도 VRM Converter for VRChat을 설치한 경우 `.vrm`도 드롭할 수 있습니다.

### 가져온 후에 일어나는 일
* **셰이더 확인** ― 아바타에 설정된 셰이더가 프로젝트에 없으면 '쉐이더 문제가 발견되었습니다'라는 메시지를 표시합니다. 이 경우 '[셰이더를 찾을 수 없는 오류](/ko/faq/missing_shader/)'를 참조하여 셰이더를 설치하세요.
* **장르 설정** ― VRChat용 아바타는 자동으로 장르가 '아바타'가 됩니다. 아바타가 아닌 Prefab(의상, 액세서리 등)을 가져오면 '의상 · 액세서리 설정' 창이 표시됩니다. 각각의 장르를 '의상', '액세서리', '기타' 중에서 고르고 <span style="color: #00b0f0">저장</span>을 누르세요. 체크를 해제한 것은 설정되지 않습니다. 장르는 나중에 편집 화면에서도 바꿀 수 있습니다.
* **미리보기 이미지 생성** ― 목록에 표시할 미리보기 이미지를 만듭니다.

## 아이템 목록
* * *
### 카드 보는 법
아이템은 카드로 표시됩니다. 카드에는 미리보기 이미지, 이름, 최종 업데이트 날짜, 붙어 있는 태그가 표시됩니다. 고정하거나 숨긴 아이템에는 각각의 표시가 붙습니다.

업로드할 수 없는 아이템에는 다음이 표시됩니다.

| 표시 | 의미 |
| ---- | ---- |
| 변환이 필요합니다 | VRM 아바타입니다. 업로드하려면 VRChat용 아바타로 변환해야 합니다. |
| 업로드할 수 없음 | VRChat용 아바타가 아니거나(VRCAvatarDescriptor가 없음) 필요한 셰이더가 프로젝트에 없습니다. 의상이나 액세서리에도 이 표시가 나옵니다. |

### 카드 조작
* 카드를 클릭하면 해당 아이템의 **편집 화면**이 열립니다.
* 카드에 마우스를 올리면 <span style="color: #00b0f0">편집</span>, <span style="color: #00b0f0">업로드</span>(장르가 '아바타'인 것만), <span style="color: #00b0f0">삭제</span> 버튼이 표시됩니다.
* 카드를 오른쪽 클릭하면 다음 메뉴가 표시됩니다.

| 메뉴 | 내용 |
| ---- | ---- |
| 고정 / 고정 해제 | 고정한 아이템은 정렬 순서와 관계없이 목록 맨 앞에 표시됩니다. |
| 숨기기 / 리스트에 표시 | 숨긴 아이템은 일반적으로 목록에 표시되지 않습니다. |
| 프로젝트에서 보기 | Unity의 Project 창에서 해당 Prefab을 표시합니다. |
| 삭제 | 아이템을 삭제합니다. |

### 검색·필터·정렬
| 기능 | 내용 |
| ---- | ---- |
| 검색 | '이름 또는 태그로 검색'에 입력하면 이름이나 태그에 입력한 문자가 포함된 아이템만 표시합니다. 입력하는 즉시 필터링됩니다. |
| 카테고리 | '아바타', '의상', '아이템 · 기타' 중에서 표시할 장르를 고를 수 있습니다. 여러 개를 선택할 수 있으며, 아무것도 선택하지 않으면 '전체'를 표시합니다. |
| 정렬 | '최종 업데이트 날짜 새로운 순', '최종 업데이트 날짜 오래된 순', '이름 순 Z-A', '이름 순 A-Z' 중에서 고를 수 있습니다. 고정한 아이템은 항상 맨 앞에 표시됩니다. |
| 태그로 필터 | 선택한 태그를 **모두** 가진 아이템만 표시합니다. 버튼에는 선택한 태그 수가 표시됩니다. |
| 숨긴 항목도 표시 | 켜면 숨긴 아이템도 목록에 표시합니다. |
| 카드 크기 | 슬라이더로 카드 크기를 바꿀 수 있습니다. 크기는 저장됩니다. |

## 태그 관리하기
* * *
태그를 사용하면 아바타나 의상을 자유롭게 분류할 수 있습니다(예: '즐겨찾기', '겨울옷', '개변 완료').
아이템에 태그를 붙이거나 떼는 것은 편집 화면의 '항목 정보'에서 합니다.([편집 화면](/ko/guides/setup/#태그))

<span style="color: #00b0f0">태그 설정</span> 버튼을 누르면 프로젝트 전체의 태그를 관리할 수 있습니다.

* **태그 추가** ― 새 태그 이름을 입력하여 추가합니다. 추가할 때 그룹을 선택할 수도 있습니다.
* **그룹 추가** ― 태그를 묶는 그룹을 만듭니다. 하나의 태그는 하나의 그룹에만 속할 수 있습니다.
* **삭제** ― 태그를 삭제하면 모든 아이템에서 해당 태그가 떨어집니다. 그룹을 삭제해도 그룹 안의 태그는 남습니다.

:::note
태그 이름과 그룹 이름은 32자까지입니다. 대문자와 소문자는 구별하지 않으며, 대소문자만 다른 태그는 같은 태그로 취급합니다.
:::

## 아이템 삭제하기
* * *
카드의 <span style="color: #00b0f0">삭제</span> 버튼, 오른쪽 클릭 메뉴, 편집 화면의 <span style="color: #00b0f0">삭제</span>에서 아이템을 삭제할 수 있습니다.

삭제를 선택하면 확인 창이 열리고 함께 삭제될 관련 에셋을 검색합니다.
EAUploader의 관리용 복사본뿐만 아니라 **가져온 원본 Prefab과 그 아이템에서만 사용하는 머티리얼·텍스처도 함께 삭제됩니다**. 다른 아이템이나 씬에서 사용하는 에셋은 삭제되지 않고 남습니다.
'Deletion details'를 열면 실제로 삭제될 파일 목록을 확인할 수 있습니다.

:::danger
삭제한 아이템과 에셋은 Unity 프로젝트에서도 삭제되며 되돌릴 수 없습니다.
삭제하기 전에 자세한 내용에서 삭제될 항목을 확인하세요.
:::

## 설정
* * *
아바타 목록 위쪽의 <span style="color: #00b0f0">설정</span> 버튼에서 다음 설정을 바꿀 수 있습니다.

| 항목 | 내용 |
| ---- | ---- |
| 언어 | EAUploader의 표시 언어를 'English', '日本語', '한국어' 중에서 고를 수 있습니다. 바꾸면 확인 메시지가 표시되고, <span style="color: #00b0f0">예</span>를 누르면 VRChat SDK를 다시 불러온 뒤 표시가 바뀝니다. |
| 테마 | 색 구성을 '라이트', '다크', '파스텔' 중에서 고를 수 있습니다. 테마는 실험적인 기능입니다. |
| 오류 보고 창 표시 | 끄면 오류가 발생해도 오류 보고를 자동으로 표시하지 않습니다. |
| 버전 | 설치된 EAUploader의 버전입니다. 문의할 때는 버전도 함께 알려 주세요. |
| 로그 보고서 열기 | EAUploader의 로그 파일이 저장된 폴더(프로젝트 폴더 바로 아래의 `EAUploaderLog`)를 엽니다. 버그를 보고할 때 로그 파일을 첨부해 주시면 원인을 조사하기 쉬워집니다. |

:::note
이전 버전에 있던 '피드백 보내기' 기능과 로그 자동 전송 기능은 현재 중단되었습니다. 의견이나 버그 보고는 [Discord](https://discord.gg/yYFru7brra) 또는 [GitHub](https://github.com/eauploader/EAUploader-for-VRChat/issues)로 보내 주세요.
:::
